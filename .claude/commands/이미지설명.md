# 이미지설명 — 페이지에 스크린샷 정리·삽입

## 입력
- $ARGUMENTS — 대상 페이지 URL (필수). 예: `http://localhost:4321/horadric-cube/transfiguration/`
- 스크린샷 소스: `C:\Users\nimto\Pictures\Screenshots\` (최근 작업한 파일들)

## 동작 규칙 (이 프로젝트 전용)

### 1. URL → 페이지 파일 매핑
- pathname 의 base path(`/d4cute` 가 있다면) 제거
- `src/content/docs<pathname>.mdx` 또는 `src/content/docs<pathname>/index.mdx` 위치 결정
- 예) `/horadric-cube/transfiguration/` → `src/content/docs/horadric-cube/transfiguration.mdx`

### 2. 이미지 후보 수집
- `C:\Users\nimto\Pictures\Screenshots\` 의 **가장 최근 날짜 그룹** PNG 들을 시간순으로 정렬
- 각 이미지를 **Read 툴로 직접 시각 분석** 하여 내용 식별 (게임 UI / 아이템 툴팁 / 메뉴 등)
- 페이지 주제와 매칭되는 이미지만 선별 (관련 없으면 제외하고 로그에 사유 기록)

### 3. 이미지 처리 규격
- 출력 폴더: `public/images<pathname>/` (예: `public/images/horadric-cube/transfiguration/`)
- 포맷: **WebP**
- 품질: **80**
- 최대 변 길이:
  - 본문 일반 이미지: **900px**
  - 메뉴 UI / 패널 캡처: **400px**
  - 아이템 툴팁 / 아이콘류: **350px** 이하
  - 작은 아이콘 / 배지: **200px** 이하
- 파일명: **kebab-case, 영문, 의미 기반**. 가격이 명시된 아이템은 가격 suffix 붙임 (예: `dust-clear-attunement-369.webp`)

### 4. 변환 실행
- `scripts/convert-screenshots.mjs` 와 mapping JSON 사용 (이미 존재). 매핑은 `scripts/.<slug>-mapping.json` 으로 생성
- mapping schema: `[{ "src": "절대경로", "out": "파일명(확장자 제외)", "maxSize": 350, "quality": 80 }]`
- 실행: `node scripts/convert-screenshots.mjs <outDir> <mappingPath>`
- 결과 stdout 에서 원본 vs 출력 해상도 확인 + 모든 파일 변환됐는지 검증

### 5. 페이지 삽입 — 컴포넌트 사용
- `import ImageModal from '../../../components/ImageModal.astro';` (상대 경로는 페이지 깊이에 따라 조정)
- 아이콘 + 호버 확대 + 클릭 시 라이트박스: **반드시** `<ImageModal>` 컴포넌트 사용
- 그룹 배치: flex row + `flex-wrap: wrap` 인라인 style 또는 별도 div 컨테이너
- 본문에서 인용하는 내용은 같은 섹션의 표·리스트로 함께 정리해서 검색 가능하게 작성

### 6. 라이트박스 (전역, 이미 셋업됨)
- `src/components/ImageLightbox.astro` 가 `overrides/MarkdownContent.astro` 에 1회 삽입되어 있음
- 추가 작업 불필요. ImageModal 의 `.img-thumb-btn` 클릭 시 자동으로 확대 모달 열림

### 7. 본문 작성 규칙
- 게임 내 한국어 명칭 우선, 괄호 안 영문 부제
- 이미지 그룹마다 **표** 로 가격/특징/사용 시점 정리
- "권장 작업 순서" 또는 "FAQ" 가 있으면 새 자원·메뉴 언급을 그쪽에도 반영
- **숫자·등급·가격은 원본 이미지에서 읽은 그대로** 기재. 추측 금지
- 출처 footer 의 `lastUpdated` 를 오늘 날짜로 갱신

### 8. 검증
- `npm run build` 통과
- 빌드 후 `dist<pathname>index.html` 에서 이미지 경로 + alt 포함 확인
- 가능하면 dev 서버 띄워 페이지에서 ImageModal 그룹 렌더링 + 라이트박스 동작 확인

### 9. 출력 (마지막)
- 변환된 파일 목록 (이름 + 해상도 + 크기)
- 추가된 섹션 요약 (제목 + 들어간 이미지 개수)
- 페이지 본문에 적용 안 한 이미지가 있으면 사유 명시

## 주의
- 이미지에 게임 내 한국어 텍스트가 보이면 그 표기를 그대로 사용 (음역·번역 금지)
- 가격/숫자 잘못 읽으면 가이드 신뢰도 손상 — 원본 이미지 재확인 후 기재
- 페이지의 기존 RecipeCard / 표 / FAQ 는 가능하면 보존, 신설 섹션 추가 형태로 갱신
- 카테고리가 페이지 주제와 다른 이미지(예: 룬 제작 메뉴가 transfiguration 페이지에 섞임)는 컨텍스트가 맞으면 "비교/안내" 섹션에 넣고, 안 맞으면 제외 사유 로그
