## 한 줄 요약

> **거래(Bargain)** 는 공물을 추가 슬롯에 올려 보상 배수를 올리는 대신 활동에 페널티(시간 단축 / 적 강도 상승 / 풀 한정)를 부과하는 시스템입니다. 빌드가 강할수록 거래 효율이 폭발적으로 올라갑니다.

## 잠금해제

지하도시 활성화 직후 거래 슬롯이 표시됩니다.

## 거래 작동 방식

1. 일반 공물 슬롯에 1~2종 선택
2. **거래 슬롯에 추가 공물 1종 올림**
3. 거래에 따른 페널티 조건 자동 적용 — 예시:
   - 시간 제한 30% 단축
   - 적 강도 +1 단계
   - 사망 시 보상 풀 손실
4. 클리어 시 거래 배수가 적용된 보상 산출

## 권장 거래 조합

| 빌드 상태 | 권장 거래 |
|----------|----------|
| 광역 처치력 매우 강함 | 시간 단축 거래 — 클리어 속도 + 보상 배수 |
| 본 빌드 어픽스 70%+ | 적 강도 거래 — 큰 보상 배수 |
| 빌드 약함 | 거래 사용 X — 일반 공물만 |

## 일반 함정

- **거래 슬롯에 너무 많이 올리기** — 페널티가 누적되어 클리어 자체가 어려워집니다.
- **시간 제한 거래 + 광역 데미지 부족 빌드** — 시간 안에 클리어 실패 시 보상이 거의 없습니다.

## FAQ

**Q. 거래 실패 시 공물은 소비되나요?**
A. 일반적으로 소비됩니다. 거래 슬롯 공물은 진입 직후 확정 소비 처리.

**Q. 거래 보상 배수는 정확히 얼마나 되나요?**
A. 페널티 종류에 따라 다르며, 시즌 패치로 자주 조정됩니다. 정확한 수치는 인게임 UI를 우선하세요.
