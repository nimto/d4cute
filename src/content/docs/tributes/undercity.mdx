## 한 줄 요약

> 지하도시는 짧고 빠른 활동입니다. 입장 전 공물/거래 세팅 1분, 클리어 4~5분, 보상 정리 1분이 표준 사이클입니다.

## 잠금해제

증오의 군주 캠페인 클리어 후 자동 활성화.

## 입장 전 체크리스트

- [ ] 공물 1~2종 선택 — 빌드 목표 일치
- [ ] (선택) 거래 슬롯에 1개 추가 — 빌드 강도 충분 시
- [ ] 활동 트리 분배 확인 — 좌/중/우 중 어느 경로인지
- [ ] 인벤토리에 매혹석/인장 빈 공간 확보

## 클리어 동선

1. **첫 3분 — 광역 처치 집중** — 적이 가장 많이 등장하는 구간
2. **중반 1분 — 미니 보스 처치** — 매혹석/인장 핵심 드롭
3. **종료 1분 — 최종 보스** — 공물 풀의 추첨 보상 산출
4. **종료 후 — 보상함 개봉** — 트리 좌측 경로일 경우 추가 보상

## 시간 관리

- **클리어 시간 단축 = 거래 배수 활성화**
- 시간 단축 거래 사용 시 30% 단축 — 평균 3분 30초 이내 클리어 필요
- 빌드의 광역 처치력이 부족하면 시간 거래는 자제

## 활동 트리 결합

- **좌측 (종료 보상)** + **무기 공물** → 일반 매혹석 풀 확장
- **중간 (조상 무기 공물 활성)** + **조상 무기 공물** → 신화 인장 시도
- **우측 (경험치 + 공물 보상)** + **자원 공물** → 가루/프리즘 보강

## 자주 묻는 질문 (FAQ)

**Q. 지하도시 클리어 실패 시 공물은 환불되나요?**
A. 환불되지 않습니다. 시간 초과/사망 시 공물은 소비 처리됩니다.

**Q. 지하도시는 파티 플레이 가능한가요?**
A. 가능합니다. 다만 공물 풀은 입장자 각자에게 별도 적용되며, 보상도 캐릭터별 산출입니다.
