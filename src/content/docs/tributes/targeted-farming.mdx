## 한 줄 요약

> **공물 종류 + 거래 슬롯 + 활동 트리 + 전쟁 계획 배치**를 한 번에 정렬하면, 원하는 인장 셋이나 매혹석을 같은 시간에 가장 높은 확률로 노릴 수 있습니다.

## 잠금해제

지하도시 + 공물 + 활동 트리가 모두 활성화된 시점부터 가능.

## 타겟 파밍 4단계 정렬

### 1. 목표 정의

- 어떤 인장/매혹석을 원하는가? — 셋 이름 또는 어픽스 카테고리 명시
- 시즌 진행도와 빌드 단계 확인

### 2. 공물 선택

- 셋 매혹석 타겟 → **의례 공물**
- 신화 인장 타겟 → **선조 무기 공물**
- 그림자 빌드 → **그림자 공물**

### 3. 거래 슬롯 결정

- 빌드 강도가 충분하면 시간 단축 거래로 배수 활성화
- 약하면 거래 없이 일반 추첨

### 4. 활동 트리 일치

- 인장 타겟 → 지하도시 중간 트리(선조 무기 공물 활성)
- 매혹석 타겟 → 좌측 트리(종료 보상 강화)
- 자원 타겟 → 우측 트리(공물 보상 강화)

## 시즌 단계별 타겟 추천

| 시즌 단계 | 1차 타겟 | 2차 타겟 |
|----------|---------|---------|
| 시즌 초 | 일반 매혹석 풀 채우기 | 인장 셋 1종 확보 |
| 시즌 중 | 셋 매혹석 완성 | 인장 셋 2~3종 |
| 시즌 말 | 신화 인장 시도 | 신화 매혹석 시도 |

## 효율 비교 (개념)

| 전략 | 같은 시간 인장 셋 확보 확률 |
|------|-------------------------|
| 공물 없이 입장 | 낮음 |
| 공물 1종 + 일반 트리 | 중간 |
| 공물 1종 + 활동 트리 중간 경로 | 높음 |
| 공물 + 거래 + 중간 트리 + 전쟁 계획 슬롯 2회 | 매우 높음 |

## FAQ

**Q. 타겟 파밍에 거래는 필수인가요?**
A. 필수는 아니지만, 빌드 강도가 충분하면 같은 시간에 보상량이 약 1.5~2배 늘어납니다.

**Q. 일반 매혹석 풀이 너무 넓어서 셋 매혹석이 잘 안 나옵니다.**
A. 큐브의 [`3-to-1 변환`](/horadric-cube/transmutation/) 으로 잉여 매혹석을 새 매혹석으로 재추첨하며 시도를 빠르게 늘립니다.
