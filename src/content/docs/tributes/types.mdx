## 한 줄 요약

> 공물은 보상 풀의 카테고리를 좁힙니다. **인장 셋 노림수**라면 의례/선조 무기, **자원 강화**라면 자원 공물을 우선합니다.

## 잠금해제

지하도시 활성화 직후 모든 공물이 드롭 풀에 포함됩니다.

## 공물 5종 정리

### 의례 공물 (Ceremonial)
- 인장 풀로 카테고리 한정
- 특정 셋 인장의 추첨 확률 증가
- 빌드 인장 셋 완성에 가장 자주 사용

### 무기 공물 (Armament)
- 무기 카테고리의 매혹석/인장
- 무기 슬롯에 직접 영향을 주는 어픽스 풀로 좁아짐

### 선조 무기 공물 (Ancestral Armament)
- 고급 풀 — 지하도시 중간 트리 활성화 시 드롭
- 신화 풀 추첨 확률 일부 포함 (드물게)
- 시즌 후반 신화 사냥의 핵심

### 그림자 공물 (Shadow)
- 그림자/저주 카테고리
- 강령술사·흑마법사 빌드에 친화적

### 자원 공물 (Resource)
- 가루·프리즘 비율 강화
- 인장 풀이 좁아지지 않으므로 자원 부족 시점 전용

## 권장 매칭

| 목표 | 권장 공물 |
|------|----------|
| 인장 셋 완성 | 의례 공물 |
| 신화 인장 시도 | 선조 무기 공물 |
| 그림자/저주 빌드 | 그림자 공물 |
| 자원 풀 보강 | 자원 공물 |
| 일반 매혹석 추첨 | 무기 공물 |

## 자원 효율 팁

- **한 번에 1~2종만 사용** — 너무 많이 사용하면 풀이 과하게 좁아져 추첨 다양성이 떨어집니다.
- **시즌 초**는 의례 공물 위주로 일반 인장 풀을 빠르게 채우는 것이 권장됩니다.
