## 지하도시 활동 트리 — "오물 적출까지만" 룰

지하도시 활동 트리는 **중앙 줄기 + 좌측 시련 분기 + 우측 공물 분기** 구조. 클랜 표준 운영은 **중앙 줄기의 "오물 적출" 노드까지만 찍고 양쪽 분기는 비활성** 유지입니다.

### 왜 오물 적출까지만 찍나?

#### 1. <span class="kw-blood">시련(Trial) 분기 — 클리어 시간 단축 강제</span>

좌측(또는 우측) **시련 노드** 는 클리어 시간 페널티가 누적되는 구간. 빌드 강도가 충분하지 않으면:

- 시작 시간 60초 → **45초/30초**로 단축
- 추가 시간 획득 페널티 -35% → **-50%** 누적
- 광역 처치 시간 안에 종료 못 하면 **클리어 실패 → 공물 환불 X**

→ **신화 병기의 공물 단독으로도 시작 45초** 인데 시련까지 누적하면 사실상 클리어 불가능. 시즌 초·중반 빌드엔 자해 트리.

#### 2. <span class="kw-blood">공물(Tribute) 강화 분기 — 다른 공물 풀 섞임</span>

반대편 **공물 강화 노드** 는 일반 공물 보상 풀까지 활성화. 문제:

- 입장 시 선택한 **상급 공물 1종의 풀이 다른 공물 풀과 섞임**
- 타겟 파밍 효율 급감 — 막대한 양의 명품화 재료를 노렸는데 일반 재료가 섞여 나옴
- 일반 풀 보상은 [큐브 변환](/horadric-cube/transmutation/) 으로도 보강 가능 → 트리 포인트 낭비

→ 상급/신화 공물의 강점인 "막대한 양" 효과를 살리려면 **다른 풀이 섞이지 않도록 비활성** 유지.

#### 3. <span class="kw-gold">"오물 적출" 까지가 보상 강화 최대 효율 지점</span>

중앙 줄기의 **오물 적출(Cleansing the Filth)** 노드는:

- 종료 보상함의 **상급 공물 풀 확률 직접 증가**
- 추가 페널티/시간 단축 없음
- 양쪽 분기에 포인트 누수 없이 도달 가능한 가장 깊은 노드

→ 거기까지 찍고 멈추는 게 **빌드 강도와 무관하게 안전 + 효율 최대**.

### 분기 분배 비교

| 분배 | 보상 효율 | 클리어 안정성 | 빌드 강도 필요 |
|------|----------|--------------|----------------|
| <span class="kw-gold">**중앙 → 오물 적출까지**</span> | <span class="kw-gold">**최대**</span> | <span class="kw-gold">**안정**</span> | <span class="kw-bone">낮음</span> |
| 중앙 + 시련 일부 | 중간 | 위험 (시간 압박) | <span class="kw-rare">높음</span> |
| 중앙 + 공물 강화 | 낮음 (풀 섞임) | 안정 | <span class="kw-bone">낮음</span> |
| 양쪽 분기 풀 분배 | 매우 낮음 | 매우 위험 | <span class="kw-mythic">매우 높음</span> |

## 봉화(Beacon) 룰 — 클랜 표준 운영

쿠라스트 지하도시 입장 시 **봉화/신호석** 을 켜는 사람의 활동 트리 분배가 파티 전체에 적용됩니다. 따라서:

:::danger[봉화 점화 규칙 — 매너 룰]

### <span class="kw-blood">오물 적출 트리를 정확히 찍은 사람만 봉화 점화</span>

- 활동 트리에 **시련 분기/공물 강화 분기를 찍은 사람이 봉화 켜면** 파티 전체가 그 페널티 또는 풀 섞임을 받음
- **시간 압박 시련 활성** → 약한 빌드 파티원이 클리어 못 함 → 모두 공물 환불 X
- **공물 강화 분기 활성** → 타겟 파밍 풀 깨짐 → 모두 손해

### 점화 자격 체크리스트

1. [ ] 지하도시 활동 트리 = **중앙 줄기 + 오물 적출까지만** 찍은 상태
2. [ ] 좌측 시련 분기 노드 **0개**
3. [ ] 우측 공물 강화 분기 노드 **0개**
4. [ ] 본인 빌드 강도 = 위력 +2 (전설 공물) 또는 +4 (신화 공물) 안정 클리어 가능

위 4가지 모두 충족 시에만 봉화 점화. 1개라도 안 맞으면 **다른 자격자에게 양보**.

### 자격 없는 사람의 운영

- 자기 캐릭으로는 공물 들고 입장만
- 봉화 점화는 자격자 (오물 적출 트리) 에게 위임
- 시즌 진행하며 자기 트리도 표준으로 재분배 → 다음 사이클부터 자격 획득

:::

> 💡 **트리 재분배 비용** — 지하도시 활동 트리는 재설정 가능 (골드 소비). 잘못 찍은 노드는 회수 후 표준 트리로 재정렬 후 자격 획득.

## 가장 이상적인 전쟁 계획 배치

상급 공물의 효율을 극대화하려면 [전쟁 계획(War Plans)](/war-plans/) 의 활동 슬롯에 지하도시를 다음 우선순위로 배치합니다.

### 시즌 단계별 배치

| 시즌 단계 | 1순위 슬롯 | 2순위 슬롯 | 권장 공물 |
|----------|-----------|-----------|----------|
| <span class="kw-bone">초반 (1주차)</span> | 헬타이드 / 속삭임 | 지하도시 (일반 매혹석) | 상급 호라드림 (부적/문장 풀) |
| <span class="kw-rare">중반 (2-3주차)</span> | **지하도시 (오물 적출 트리)** | 악몽 던전 | 상급 독창성 (가루) + 상급 정련 (명품화) |
| <span class="kw-legendary">후반 (빌드 완성)</span> | **지하도시 (오물 적출 트리)** | 우두머리 처치 | 상급 조화 (룬) + 상급 병기 (선조 전설) |
| <span class="kw-mythic">시즌 마감</span> | **지하도시 (신화 도전)** | 보스 트로피 | <span class="kw-mythic">신화 병기</span> (위력 +4 견딜 빌드만) |

### 사이클 운영

1. **전쟁 계획 5단계 활성화** → 함 전리품 보장 + 지하도시 슬롯 진입 권한
2. **공물 1~2종 + (선택) 거래 1종** 세팅 — 빌드 강도에 맞게
3. **봉화 점화** (자격자) → 파티 진입
4. **클리어 + 종료 보상함** → 상급 공물 풀에서 추첨
5. **사이클당 평균 4-5분** → 시간당 12-15회 가능

## 시련 + 공물 양쪽 찍으면 안 되는 이유 (요약)

- <span class="kw-blood">시련</span> = 시간 페널티 누적 → 빌드 강도 부족 시 **클리어 실패 + 공물 환불 X**
- <span class="kw-blood">공물 강화</span> = 다른 공물 풀 활성 → **상급 공물의 "막대한 양" 효과 희석**
- 양쪽 동시 = **클리어 실패 + 보상 풀 망함** → 시간/공물 둘 다 손해
- 트리 포인트는 한정 자원 → **중앙 줄기 깊이에 모두 투자** 가 최적해

## FAQ

**Q. 조율 등급 1 이상이 정확히 뭔가요?**
A. 지하도시 클리어 후 종료 보상 화로의 **조율(Attunement) 진행도**. 클리어 1회 = 1성 — 즉 정상 클리어만 하면 1 이상 자동 달성. 시간 초과/사망으로 종료 실패 시 0 → 상급 공물 효과 발동 X.

**Q. 신화 병기의 공물은 언제 쓰는 게 효율적인가요?**
A. **빌드가 위력 +4 안정 클리어 가능 + 추가 시간 -50% 페널티 안에서 광역 처치 가능** 시. 보통 시즌 후반 (3-4주차+) 빌드 완성 후. 신화 고유 추첨도 시즌 마감 단계.

**Q. 양쪽 분기에 한두 개씩만 찍어도 정말 손해인가요?**
A. **네.** 시련 노드 1개라도 시간 페널티 누적, 공물 강화 노드 1개라도 풀 섞임 시작. 클랜 봉화 룰은 **0개 기준** 입니다.

**Q. 봉화를 자격 없는 사람이 켰을 때 활동 취소 가능한가요?**
A. **불가능** — 봉화 점화 = 입장 확정. 공물 사용 + 사이클 시간 모두 소진. 사전에 자격 확인이 유일한 방어.

**Q. 신화 병기의 공물 9개, 상급 정련 41개 등 보유량이 다른 이유?**
A. **상급 공물별 드롭률 차이** — 시련/일반 활동 보상 + 큐브 합성. 신화 병기는 가장 희귀 (사이클 다수 누적 필요), 상급 정련은 명품화 수요 맞춰 풍족하게 드롭.

**Q. 거래(Bargain) 슬롯에 상급 공물을 올려도 되나요?**
A. 가능하지만 **빌드가 위력 +2/+4 위에 추가 거래 페널티까지 견딜 때만**. 보통 시즌 후반 신화 도전 단계에서만 권장.
