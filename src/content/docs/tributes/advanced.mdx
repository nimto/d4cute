## 한 줄 요약

> **나한투의 쿠라스트 지하도시 (고행 난이도 전용)** 의 상급 공물은 **전설 5종 + 신화 1종**. <span class="kw-gold">**조율 등급 1 이상으로 완료**</span> 해야 막대한 보상이 떨어집니다. 활동 트리는 <span class="kw-gold">**좌측 줄기 "오물 적출" 까지만 찍기**</span> — 봉화 점화 시 <span class="kw-gold">**차원문 장난꾼(Portal Prankster)** 추첨 확률을 부여</span> 받아 마지막 보스 후 **보너스 상자**를 노리는 게 진짜 목적. 시련/공물 강화 분기는 페널티만 누적되므로 비활성 유지.

:::tip[게임 내 공식 명칭 기준]

## 지하도시 활동 트리 — "오물 적출까지만" 룰

지하도시 활동 트리는 **좌측 줄기 (메인 — 오물 적출 노드 포함) + 시련 분기 + 공물 강화 분기** 구조. 클랜 표준 운영은 **좌측 줄기의 "오물 적출" 노드까지만 찍고 두 분기는 비활성** 유지입니다.

### 차원문 장난꾼(Portal Prankster) 메커니즘

오물 적출까지 찍는 진짜 이유 = <span class="kw-gold">**봉화 점화 시 차원문 장난꾼이 등장할 확률**</span> 을 얻기 위함:

- 차원문 장난꾼 = **지하도시 전용 보물 고블린**. 일반 보물 고블린과 달리 던전 안에서만 등장.
- **차원문 사이로 도망 → 짧은 시간 안에 추격 처치 필요** (광역/추격 빌드 유리).
- 처치 성공 시 <span class="kw-gold">**마지막 보스 처치 후 종료 시점에 보너스 상자 1개 추가**</span> 등장.
- 보너스 상자 = <span class="kw-gold">**공물 · 룬 · 추가 아이템**</span> 등 좋은 보상.
- **패치 2.0.4 이후** — 보너스 상자도 **거래(Bargain) 보상 강화 영향 받음** ([Wowhead 패치 노트](https://www.wowhead.com/diablo-4/news/kurast-undercity-portal-prankster-chests-will-be-affected-by-bargains-diablo-4-349279)).
- 적은 확률이라 모든 사이클에 등장하진 않지만, **봉화 켤 때마다 추첨**. 사이클 누적할수록 보너스 누적.

→ **봉화 점화 = 차원문 장난꾼 추첨 트리거**. **오물 적출 노드를 안 찍은 사람이 봉화 켜면 추첨 확률 0** = 파티 전체 보너스 기회 손실.

### 그러면 왜 시련 / 공물 강화 분기는 안 찍나?

차원문 장난꾼 효과는 **오물 적출 1개 노드만으로 확보**. 그 너머 분기는 **부수 효과 없이 페널티만 누적**:

#### 1. <span class="kw-blood">시련(Trial) 분기 — 클리어 시간 단축</span>

**시련 분기** 노드는 클리어 시간을 직접 깎습니다:

- 시작 시간 60초 → **45초/30초** 까지 단축
- 추가 시간 획득 페널티 -35% → **-50%** 누적
- 광역 처치 시간 안에 종료 못 하면 **클리어 실패 → 공물 환불 X**
- **차원문 장난꾼 등장해도 추적 처치 시간 부족** → 보너스 상자 기회까지 잃음

→ **신화 병기의 공물 단독으로도 시작 45초** 인데 시련 분기까지 누적하면 사실상 클리어 불가능. 시즌 초·중반 빌드엔 자해.

#### 2. <span class="kw-blood">공물(Tribute) 강화 분기 — 보상 풀 희석</span>

**공물 강화 분기** 노드는 일반 공물 보상 풀까지 활성화시킵니다:

- 입장 시 선택한 **상급 공물 1종의 풀이 일반 공물 풀과 섞임**
- 타겟 파밍 효율 급감 — 막대한 양의 명품화 재료를 노렸는데 일반 잡템이 섞여 나옴
- 일반 풀 보상은 [큐브 변환](/horadric-cube/transmutation/) · [3-to-1 매혹석 변환](/talismans/) 으로도 보강 가능 → 트리 포인트 낭비

→ 상급/신화 공물의 강점인 "막대한 양" 효과를 살리려면 **다른 풀이 섞이지 않도록 비활성** 유지.

#### 3. <span class="kw-gold">"오물 적출" 까지가 트리 효율의 정점</span>

좌측 줄기의 **오물 적출(Cleansing the Filth)** 노드는:

- 봉화 활성화 시 **차원문 장난꾼 등장 확률** 부여 — 보너스 상자 기회
- 추가 페널티/시간 단축 **없음**
- 시련/공물 강화 분기에 포인트 누수 없이 도달 가능한 가장 깊은 노드

→ 거기까지 찍고 멈추는 게 **빌드 강도와 무관하게 안전 + 보너스 상자 추첨 가동 + 다른 페널티 0**.

### 분기 분배 비교

| 분배 | 보너스 상자 추첨 | 클리어 안정성 | 보상 풀 순도 | 빌드 강도 필요 |
|------|---------------|--------------|------------|----------------|
| <span class="kw-gold">**좌측 → 오물 적출까지**</span> | <span class="kw-gold">**O (확률 부여)**</span> | <span class="kw-gold">**안정**</span> | <span class="kw-gold">**순수**</span> | <span class="kw-bone">낮음</span> |
| 좌측 + 시련 분기 추가 | O | <span class="kw-blood">위험 (시간 압박)</span> | <span class="kw-gold">순수</span> | <span class="kw-rare">높음</span> |
| 좌측 + 공물 강화 분기 추가 | O | 안정 | <span class="kw-blood">희석</span> | <span class="kw-bone">낮음</span> |
| 시련 + 공물 강화 양쪽 추가 | O | <span class="kw-blood">매우 위험</span> | <span class="kw-blood">희석</span> | <span class="kw-mythic">매우 높음</span> |

→ **추첨 확률은 오물 적출 1개 노드로 얻는 것**. 추가 분기는 모두 페널티만 누적. 트리 포인트는 한정 자원 → **좌측 줄기 깊이 (오물 적출까지) 에 모두 투자** 가 최적해.

## 봉화(Beacon/Brazier) 룰 — 클랜 표준 운영

쿠라스트 지하도시 입장 시 던전 내 **봉화** 를 켜야 다음 층 진행 + 차원문 장난꾼 추첨이 시작됩니다. **봉화를 켜는 사람의 활동 트리 분배** 가 추첨 확률·페널티에 영향을 주므로 점화 자격이 중요합니다.

:::danger[봉화 점화 규칙 — 공팟/클랜 매너 룰]

### <span class="kw-blood">오물 적출 노드를 찍은 사람만 봉화 점화</span>

- **오물 적출 노드를 찍지 않은 사람이 점화하면 차원문 장난꾼 추첨 확률 0** → 파티 전체 보너스 상자 기회 손실
- **시련 분기까지 찍은 사람이 점화하면** → 클리어 시간 단축 페널티가 파티 클리어 안정성을 위협
- **공물 강화 분기까지 찍은 사람이 점화하면** → 타겟 파밍 풀 희석 → 모두가 의도한 보상 못 받음

### 점화 자격 체크리스트

1. [ ] 지하도시 활동 트리 = **좌측 줄기 + 오물 적출까지만** 찍은 상태
2. [ ] 시련 분기 노드 **0개**
3. [ ] 공물 강화 분기 노드 **0개**
4. [ ] 본인 빌드 강도 = 위력 +2 (전설 공물) 또는 +4 (신화 공물) 안정 클리어 가능

위 4가지 모두 충족 시에만 봉화 점화. 1개라도 안 맞으면 **다른 자격자에게 양보**.

### 자격 없는 사람의 운영

- 자기 캐릭으로는 공물 들고 입장만
- 봉화 점화는 자격자 (오물 적출 트리 + 시련/공물 분기 0) 에게 위임
- 시즌 진행하며 자기 트리도 표준으로 재분배 → 다음 사이클부터 자격 획득

:::

> 💡 **트리 재분배 비용** — 오물 적출 노드 환불 비용 = <span class="kw-rare">**5천만 골드**</span> (게임 내 툴팁 확인). 잘못 찍은 시련/공물 분기 노드는 회수해서 좌측 줄기로 재투자.

## 가장 이상적인 전쟁 계획 배치

상급 공물의 효율을 극대화하려면 [전쟁 계획(War Plans)](/war-plans/) 의 활동 슬롯에 지하도시를 다음 우선순위로 배치합니다.

### 시즌 단계별 배치

| 시즌 단계 | 1순위 슬롯 | 2순위 슬롯 | 권장 공물 |
|----------|-----------|-----------|----------|
| <span class="kw-bone">초반 (1주차)</span> | 헬타이드 / 속삭임 | 지하도시 (일반 매혹석) | 상급 호라드림 (부적/문장 풀) |
| <span class="kw-rare">중반 (2-3주차)</span> | **지하도시 (오물 적출 트리)** | 악몽 던전 | 상급 독창성 (가루) + 상급 정련 (명품화) |
| <span class="kw-legendary">후반 (빌드 완성)</span> | **지하도시 (오물 적출 트리)** | 우두머리 처치 | 상급 조화 (룬) + 상급 병기 (선조 전설) |
| <span class="kw-mythic">시즌 마감</span> | **지하도시 (신화 도전)** | 보스 트로피 | <span class="kw-mythic">신화 병기</span> (위력 +4 견딜 빌드만) |

### 사이클 운영

1. **전쟁 계획 5단계 활성화** → 함 전리품 보장 + 지하도시 슬롯 진입 권한
2. **공물 1~2종 + (선택) 거래 1종** 세팅 — 빌드 강도에 맞게
3. **봉화 점화** (자격자) → 파티 진입
4. **클리어 + 종료 보상함** → 상급 공물 풀에서 추첨
5. **사이클당 평균 4-5분** → 시간당 12-15회 가능

## 시련 + 공물 양쪽 찍으면 안 되는 이유 (요약)

- <span class="kw-gold">오물 적출 노드 1개</span>만 찍어도 차원문 장난꾼 추첨 확률 발생 — 보너스 상자 효과는 이미 확보됨
- <span class="kw-blood">시련 분기</span> = 시간 페널티 누적 → 빌드 부족 시 **클리어 실패 + 공물 환불 X + 차원문 장난꾼 추적 시간 부족**
- <span class="kw-blood">공물 강화 분기</span> = 다른 공물 풀 활성 → **상급 공물의 "막대한 양" 효과 희석**
- 양쪽 동시 = **클리어 실패 + 보상 풀 망함** → 시간/공물 둘 다 손해
- 트리 포인트는 한정 자원 → **좌측 줄기 깊이 (오물 적출까지) 에 모두 투자** 가 최적해

## FAQ

**Q. 조율 등급 1 이상이 정확히 뭔가요?**
A. 지하도시 클리어 후 종료 보상 화로의 **조율(Attunement) 진행도**. 클리어 1회 = 1성 — 즉 정상 클리어만 하면 1 이상 자동 달성. 시간 초과/사망으로 종료 실패 시 0 → 상급 공물 효과 발동 X.

**Q. 신화 병기의 공물은 언제 쓰는 게 효율적인가요?**
A. **빌드가 위력 +4 안정 클리어 가능 + 추가 시간 -50% 페널티 안에서 광역 처치 가능** 시. 보통 시즌 후반 (3-4주차+) 빌드 완성 후. 신화 고유 추첨도 시즌 마감 단계.

**Q. 양쪽 분기에 한두 개씩만 찍어도 정말 손해인가요?**
A. **네.** 시련 노드 1개라도 시간 페널티 누적, 공물 강화 노드 1개라도 풀 섞임 시작. 차원문 장난꾼 추첨 확률은 오물 적출 1개 노드로 이미 확보되므로 그 너머 분기는 페널티만 추가. 클랜 봉화 룰은 **0개 기준**.

**Q. 차원문 장난꾼은 매번 등장하나요?**
A. **아닙니다** — "낮은 확률" (게임 내 툴팁 원문) 로 봉화 점화 시 추첨됩니다. 사이클을 누적할수록 보너스 상자 빈도가 산술적으로 오릅니다. 패치 2.0.4 이후 보너스 상자도 [거래(Bargain)](/tributes/bargains/) 효과 적용.

**Q. 차원문 장난꾼을 놓치면 어떻게 되나요?**
A. **추적 처치 실패 시 보너스 상자 없음**. 차원문 사이로 도망가므로 광역/이동기 빌드가 유리. 시련 분기까지 찍어 시간이 더 짧아진 상태면 추격 자체가 불가능.

**Q. 봉화를 자격 없는 사람이 켰을 때 활동 취소 가능한가요?**
A. **불가능** — 봉화 점화 = 진행 확정. 공물 사용 + 사이클 시간 모두 소진. 사전에 자격 확인이 유일한 방어.

**Q. 신화 병기의 공물 9개, 상급 정련 41개 등 보유량이 다른 이유?**
A. **상급 공물별 드롭률 차이** — 시련/일반 활동 보상 + 큐브 합성. 신화 병기는 가장 희귀 (사이클 다수 누적 필요), 상급 정련은 명품화 수요 맞춰 풍족하게 드롭.

**Q. 거래(Bargain) 슬롯에 상급 공물을 올려도 되나요?**
A. 가능하지만 **빌드가 위력 +2/+4 위에 추가 거래 페널티까지 견딜 때만**. 보통 시즌 후반 신화 도전 단계에서만 권장.
