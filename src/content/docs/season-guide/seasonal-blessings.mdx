## 한 줄 요약

> <span class="kw-blood">**이글거리는 재 (Smoldering Ash)**</span>는 시즌 등급 보상으로 얻는 시즌 캐릭터 전용 자원입니다. <span class="kw-gold">**시즌 축복 (Seasonal Blessings)**</span> 5종에 분배해 시즌 캐릭터 전체에 영구 버프를 적용합니다. 총 <span class="kw-blood">**20개**</span>로 모든 축복 풀 잠금해제 가능.

:::tip[용어 정리 — 헷갈리지 마세요]
- <span class="kw-blood">**이글거리는 재**</span> ≠ <Term id="resplendent-spark" /> (반짝이는 벼락불)
  - **이글거리는 재** = 시즌 축복 잠금해제용 (시즌 보너스 버프)
  - **반짝이는 벼락불** = 신화 고유 제작용 (장비)
- 시즌 8부터 시즌 축복이 시즌 패스에서 **시즌 등급**으로 이동됨
:::

## 잠금해제

- 시즌 캐릭터 + 시즌 등급 진행 시작 시 자동 활성화
- 게임 내 메뉴: **시즌 등급 → 시즌 축복 탭** 에서 분배

## 각 축복 상세 설명

### 1. 골동품의 항아리

- **효과**: 골동품 상인에게서 아이템 구매 시 두 번째 아이템도 추가 획득
- **언제 가치 ↑**: 시즌 도전 외형·룬 등을 골동품 상인에게서 많이 구매할 때
- **언제 가치 ↓**: 빌드 위주 진행이라 골동품 상인을 자주 안 갈 때
- <span class="kw-bone">**우선순위**</span>: 시즌 후반 (외형/룬 누적 단계)

### 2. 회수의 항아리

- **효과**: 아이템 분해로 희귀 재료 (잊힌 영혼 · 미지의 수정 등) 추가 획득 확률
- **언제 가치 ↑**: <Term id="masterworking" /> + 명품화 자원이 부족한 빌드 진행 중
- **언제 가치 ↓**: 이미 자원이 풍부한 시즌 후반
- <span class="kw-gold">**우선순위**</span>: 시즌 초중반 (빌드 빌드업 가속)

### 3. 명품화의 항아리

- **효과**: <Term id="masterworking" /> 핵심 재료 (옵두사이트) 추가 획득 확률
- **언제 가치 ↑**: 빌드 완성 단계에서 명품화 횟수 대량 필요
- **언제 가치 ↓**: 명품화 시작 전 시즌 극초반
- <span class="kw-gold">**우선순위**</span>: 빌드 완성 시기 + 핵심 부위 명품화 시도 시

### 4. 문양의 항아리 — <span class="kw-gold">**최우선 분배 추천**</span>

- **효과**: <Term id="glyph" /> 강화 시 보너스 업그레이드 확률 → 만렙 (21레벨) 도달 시간 단축
- **언제 가치 ↑**: 시즌 초중반 (모든 클래스가 문양 21레벨 도달이 빌드 완성의 척도)
- **언제 가치 ↓**: 이미 모든 문양이 21레벨 도달한 후
- <span class="kw-gold">**우선순위**</span>: <span class="kw-gold">**시즌 시작 직후 첫 분배**</span> — 모든 빌드의 공통 가속

### 5. 선조 속삭임의 항아리

- **효과**: <Term id="ancestral" /> 보관함이 속삭임 보상에서 등장할 확률 ↑
- **언제 가치 ↑**: 어픽스 풀이 부족한 시즌 초중반 (선조 어픽스 = 시즌 빌드 핵심)
- **언제 가치 ↓**: 어픽스 풀 완성 후
- <span class="kw-gold">**우선순위**</span>: 시즌 초반 (빌드 아이템 풀 가속)

## 분배 우선순위 — 시즌 진행별

|---------|----------------------|

| <span class="kw-rare">**2-3주차 (빌드 빌드업)**</span> | ③ 선조 속삭임의 항아리 → ④ 명품화의 항아리 |

> 💡 **위 순서는 모든 빌드 공통 가이드**입니다. 본인의 빌드가 특정 자원에 더 의존하면 우선순위를 조정하세요.

## 이글거리는 재 누적 경로

| 경로 | 누적량 | 비고 |
|------|--------|------|
| 시즌 목표 완료 | 각 목표마다 1-2개 | 시즌 등급 메뉴의 "목표" 탭 |
| 장 보상함 | 등급마다 다수 | 등급 클리어 시 자동 |
| 명성 보상 (스코보스 군도) | 일부 | 명성 단계 보상 |
| 시즌 패스 (무료 트랙) | 일부 | 일부 단계에서 보너스 |

**총 누적 ~20개** → 모든 시즌 축복 풀 잠금해제 가능

## 자원 절약 팁

:::tip[효율 극대화]
- <span class="kw-gold">**시즌 시작 직후 첫 분배는 문양의 항아리**</span> — 모든 빌드의 빌드 완성 가속
- <span class="kw-blood">**되돌리기 가능 여부 확인**</span> — 일부 시즌은 환불 가능, 일부는 불가능. 시즌 13은 환불 기능 활성화 (시즌 메뉴 확인)
- <span class="kw-bone">**시즌 패스 보너스 트랙도 확인**</span> — 무료 트랙에도 일부 이글거리는 재 포함
- <span class="kw-gold">**모든 축복 100% 활성화는 시즌 종료 전까지 충분**</span> — 무리하게 시즌 초 모든 목표 클리어할 필요 없음
:::

## FAQ

**Q. 시즌이 끝나면 시즌 축복 효과는 어떻게 되나요?**
A. 시즌 종료와 함께 사라집니다. 시즌 캐릭터가 영원 서버로 이전되면 축복 효과는 사라지고, 영원 캐릭터는 시즌 축복을 사용할 수 없습니다.

**Q. 시즌 13 환불은 어떻게 하나요?**
A. 시즌 메뉴 → 시즌 등급 → 시즌 축복 탭 → 분배한 항아리 클릭 → 환불 옵션이 있으면 시도 가능 (시즌별로 다름). 자세한 비용은 게임 내 확인.

**Q. 이글거리는 재가 부족한데 어떻게 더 얻나요?**
A. 시즌 목표 100% + 명성 100% + 시즌 패스 보너스 트랙 모두 진행하면 20개 누적이 가능합니다. 시즌 후반까지 충분.

**Q. 시즌 13 다음 시즌 (시즌 14) 축복은 어떻게 되나요?**
A. 시즌마다 축복 종류가 1-2개 바뀝니다. 시즌 14 출시 시 새 페이지가 추가되며, 본 페이지는 `archive/season-13/` 으로 이동하여 영구 보존됩니다.

**Q. "이글거리는 재" 와 "반짝이는 벼락불" 이 다른 건가요?**
A. **다릅니다**. 이글거리는 재 = 시즌 축복용 / <Term id="resplendent-spark" /> = 신화 고유 제작용. 시즌 등급 보상에서 둘 다 획득 가능합니다.
