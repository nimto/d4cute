## 한 줄 요약

> <span class="kw-gold">**시즌 여정**</span>은 시즌 11부터 <span class="kw-gold">**시즌 등급(Season Tier)**</span>으로 명칭 변경. 챕터(장) 단위로 보상을 받고, 각 등급의 캡스톤 던전을 완료해야 다음 등급으로 진출합니다. 시즌 13의 핵심 보상 — <span class="kw-blood">**이글거리는 재 (Smoldering Ash)**</span>로 시즌 축복을 선택할 수 있고, <span class="kw-mythic">**반짝이는 벼락불 14개**</span>로 신화 고유를 제작합니다.

:::tip[용어 정리]
- **시즌 여정 = 시즌 등급** (시즌 11부터 명칭 변경, 공식)
- **장 (Chapter)** = 시즌 등급 단계 (1장, 2장, …)
- **캡스톤 던전** = 등급 간 진출 던전 (시즌 등급에만 사용)
:::

### 3분 안에 핵심만

- **시즌 등급 = 시즌 여정**: 명칭만 변경, 시스템은 비슷
- **장 보상**: 전설 아이템 + 담금질 설명서 보관함 + <Term id="resplendent-spark" />

- **시즌 13 특별 보상**: <Term id="resplendent-spark" /> 14개 (신화 고유 7개 제작 가능)

## 잠금해제

- 시즌 캐릭터 생성 후 자동 활성화
- 시즌 캐릭터: 결전의 시즌 (시즌 13) 시작 시 새 캐릭터 또는 기존 영원 캐릭터 → 시즌 영역으로 이전

## 시즌 등급 구조

### 등급별 진행

1. **현재 등급의 시즌 목표** 완료 (예: 보스 처치, 던전 클리어, 명성 누적 등)
2. **장 보상함** 수령 → 전설 아이템 + <Term id="resplendent-spark" /> + <span class="kw-blood">이글거리는 재</span> 등
3. **캡스톤 던전** 완료 → 다음 등급 진출
4. 새 등급의 목표 진행 → 반복

### 시즌 13 장(章) 핵심 보상 — 추정

| 단계 | 주요 보상 (시즌 13 기준) |
|------|----------------------|
| <span class="kw-bone">**초반장**</span> | 일반 전설 + 명성 + <Term id="forgotten-soul" /> 묶음 |
| <span class="kw-rare">**중반장**</span> | <Term id="resplendent-spark" /> 1-2개 + 이글거리는 재 누적 |
| <span class="kw-gold">**고난도장**</span> | <Term id="resplendent-spark" /> 다수 + 이글거리는 재 + 시즌 외형 |
| <span class="kw-mythic">**최종장**</span> | 시즌 한정 외형 + 시즌 보스 입장권 |

> ⚠ 정확한 장별 보상 수치는 시즌 진행 중 패치로 변동될 수 있습니다. 본 표는 시즌 13 시작 시점 기준입니다.

## 이글거리는 재 — 시즌 등급에서 얻는 법

<Term id="resplendent-spark" />는 신화 고유 제작용, <span class="kw-blood">**이글거리는 재**</span>는 시즌 축복 잠금해제용입니다. 두 가지를 헷갈리지 않도록 주의.

### 이글거리는 재 획득 경로

| 경로 | 횟수 | 비고 |
|------|------|------|
| <span class="kw-gold">**시즌 목표 완료**</span> | 다수 | 각 등급마다 여러 개의 시즌 목표 |
| <span class="kw-gold">**장 보상함**</span> | 등급마다 1-3개 | 등급이 올라갈수록 다량 |
| <span class="kw-bone">**시즌 패스**</span> | 일부 단계 | 시즌 패스 진행 중 보너스 트랙 |

**총합** — 시즌 등급 완주 시 약 <span class="kw-blood">**20개**</span> 누적 (모든 시즌 축복 잠금해제 가능)

## 진행 팁

### 캡스톤 던전 빠르게 통과

1. 본인의 빌드 레벨이 캡스톤 권장 기준에 도달했는지 확인 (보통 추천 단계 -2 이내)
2. 보스 패턴 사전 학습 → 첫 시도에서 실패 시 자원 손실 위험
3. 일부 캡스톤은 **시간 제한**이 있음 → 단일 처치력 부족하면 광역 빌드 잠시 교체

### 빠른 진행 우선순위

| 우선 | 항목 | 이유 |
|------|------|------|
| 1 | 캠페인 + 캠페인 보상 | 시즌 등급 1-2장 자동 진행 |
| 2 | 시즌 보스 1회 처치 | 시즌 목표 + <Term id="resplendent-spark" /> |
| 3 | 헬타이드 1-2회 | 시즌 목표 + <Term id="forgotten-soul" /> 누적 |
| 4 | 악몽 던전 1-3회 | 시즌 목표 + <Term id="glyph" /> 경험치 |
| 5 | 명성 채우기 | 명성 보상함은 이글거리는 재 포함 가능 |

### 시즌 보스 입장권

- 시즌 13 최종 보스 = <Term id="echo-of-mephisto" />
- 입장권 = <Term id="trace-of-echoes" /> 10개 통합 또는 <Term id="echoing-hatred" /> 활동 보상

## 자원 우선순위

:::tip[효율 극대화]
- <span class="kw-gold">**이글거리는 재 우선**</span> — 시즌 축복 효과는 즉시 모든 캐릭터에 적용되므로 가장 큰 시간 절약
- <span class="kw-mythic">**반짝이는 벼락불은 후반에 누적**</span> — 신화 고유 7개까지 제작 가능 (14개 ÷ 2)
- <span class="kw-blood">**캡스톤 던전은 빌드 완성 후**</span> — 무리하게 도전하면 시간 손실
- <span class="kw-bone">**1주차 권장 진행**</span> — 캠페인 → 시즌 목표 → 명성 → 4장 도달 → 빌드 완성
:::

## FAQ

**Q. 시즌 여정과 시즌 등급은 같은 건가요?**
A. 같습니다. 시즌 11부터 공식 명칭이 "시즌 여정" → "시즌 등급" 으로 변경되었습니다. 게임 내 메뉴에는 "시즌 등급" 으로 표시됩니다.

**Q. 캡스톤 던전을 못 깨면 진행이 막히나요?**
A. 네, 다음 등급으로 못 갑니다. 빌드 강화 (어픽스 · 명품화 · 보석 · 룬) 후 재도전 권장.

**Q. 이글거리는 재가 부족한데 어떻게 더 얻나요?**
A. 명성 보상함을 모두 열고, 시즌 목표 100% 완료하면 20개 누적 가능합니다. 시즌 패스 무료 트랙에도 일부 포함됩니다.

**Q. 시즌 보상은 영원 캐릭터로 가져갈 수 있나요?**
A. 시즌 종료 후 시즌 캐릭터의 모든 아이템·진행도가 영원 서버로 이전됩니다.

**Q. 시즌 14가 시작되면 이 가이드는 어떻게 되나요?**
A. 시즌 14 출시 시 본 페이지는 `archive/season-13/seasonal-journey/` 로 이동되어 영구 보존됩니다. 시즌 14용 신규 페이지가 메인 URL을 가집니다. 자세한 전략은 [시즌 가이드 개요](/season-guide/) 참고.
