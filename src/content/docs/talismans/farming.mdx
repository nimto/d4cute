## 한 줄 요약

> 부적은 헬타이드(매혹석 위주) + 쿠라스트 지하도시(인장 위주) 두 축으로 모읍니다. 신화 등급은 거래 불가, 그 외는 거래 가능합니다.

## 잠금해제

부적 슬롯 활성화 후 모든 파밍 동선이 작동.

## 매혹석 파밍 동선

| 활동 | 등급 풀 |
|------|---------|
| 헬타이드 | 일반~전설 다수, 셋 매혹석 일정 확률 |
| 헬타이드 (좌측 트리) | 셋 매혹석 비율 추가 상승 |
| 헬타이드 (중간 트리) | 보스 트로피 — 신화 매혹석 추첨 자원 |
| 둥지 보스 | 유니크 매혹석 직접 드롭 |
| 둥지 보스 (신화 풀 노드) | 신화 매혹석 시도 |

## 인장 파밍 동선

| 활동 | 등급 풀 |
|------|---------|
| 쿠라스트 지하도시 | 매직~전설 다수 |
| 지하도시 (좌측 트리) | 종료 보상 강화 — 매혹석/인장 함께 |
| 지하도시 (중간 트리) | 선조 무기 공물 — 인장 타겟 |
| 공물 사용 | 인장 셋을 좁혀 추첨 |
| 보스 트로피 추첨 | 신화 인장 시도 |

## 권장 일일 루틴

1. 전쟁 계획 5단계에 헬타이드 + 지하도시 각각 1회 이상 포함
2. 지하도시 진입 직전 공물 선택 — 부족한 셋을 좁혀 추첨
3. 활동 종료 후 일반/매직 즉시 분해 → 수지 누적
4. 누적 수지로 큐브에서 셋 매혹석 리롤 또는 유니크 매혹석 제작

## 거래 규정 (3.0.2 기준)

- **거래 가능**: 비신화 매혹석 + 비신화 인장 (Soulbound 표시가 없는 한)
- **거래 불가**: 신화 매혹석, 신화 인장, 시즌 한정 화폐
- **거래 채널**: 게임 내 거래 + 공식 거래 게시판(있을 경우)

## 함정 / 흔한 실수

- **인장 풀에 공물 없이 진입** — 풀이 넓어 원하는 셋 확률이 매우 낮음. 진입 직전 공물 선택 필수
- **신화 매혹석을 분해** — 분해 보상이 거래 가치를 넘지 못합니다. 보관 또는 사용 후 결정

## FAQ

**Q. 공물이 부족합니다. 빠른 공물 누적법은?**
A. [공물 가이드](/tributes/) 참고. 지하도시 우측 트리의 공물 보상 강화 노드가 누적에 가장 큰 도움이 됩니다.

**Q. 매혹석 인벤토리 칸이 부족합니다.**
A. 비밀 레시피 [`3-to-1 변환`](/horadric-cube/transmutation/) 으로 잉여 매혹석을 새 매혹석으로 재추첨하는 것이 인벤토리 정리의 표준 방식입니다.
