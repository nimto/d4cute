## 한 줄 요약

> 활동 5개 중 일부는 단일 보스용, 일부는 광역 누적용입니다. 자원 목표에 맞춰 5단계를 구성하면 같은 시간에 최대 효율을 냅니다.

## 잠금해제

전쟁 계획 메뉴 활성화 직후 모든 활동이 슬롯에 선택 가능합니다. 단, 일부 활동은 **고난도 단계 상승**에 따라 보상이 강화됩니다.

## 6대 활동 비교

| 활동 | 한글 | 주 목적 |
|------|------|---------|
| Nightmare Dungeon | 악몽 던전 | 문양(Paragon Glyph) 레벨업 |
| Helltide | 헬타이드 | 오픈 월드, 매혹석·신더(Cinder) 보상 |
| The Pit | 균열 | 명품화(Masterworking) 재료 |
| Infernal Hordes | 지옥의 무리 | 웨이브 생존, 작열하는 정수(Burning Aether) |
| Lair Boss | 둥지 보스 | 유니크·신화 유니크 직접 드롭 |
| Kurast Undercity | 쿠라스트 지하도시 | 타임어택, 공물(Tribute) 기반 보상 |

## 활동별 상세

### 1. 악몽 던전 (Nightmare Dungeon)
- **소요 시간**: 5~10분
- **핵심 보상**: 문양 XP, 보조 가루
- **권장 배치 슬롯**: 1~2 (체인 초반 / 문양 비중이 큰 빌드의 메인 슬롯)

### 2. 헬타이드 (Helltide)
- **소요 시간**: 10~20분
- **핵심 보상**: 매혹석/인장, 신더 상자, 보스 트로피 (트리 의존)
- **권장 배치 슬롯**: 2~3 (활동 트리 중간 경로의 보스 트로피 누적용)

### 3. 균열 (The Pit)
- **소요 시간**: 5~10분 (1층 기준)
- **핵심 보상**: 명품화 재료, Pure Dust 시도
- **권장 배치 슬롯**: 4~5 (체인 후반에 가장 강한 빌드 상태로 돌입)

### 4. 지옥의 무리 (Infernal Hordes)
- **소요 시간**: 10분 내외
- **핵심 보상**: Burning Aether, 보조 가루
- **권장 배치 슬롯**: 2~4

### 5. 둥지 보스 (Lair Boss)
- **소요 시간**: 3~5분 (열쇠 1회)
- **핵심 보상**: 유니크/신화 유니크 직접 드롭, 보스 트로피
- **권장 배치 슬롯**: 1 또는 5 (빠른 시작 / 강력한 마무리)

### 6. 쿠라스트 지하도시 (Kurast Undercity)
- **소요 시간**: 5분 이내 (타임어택)
- **핵심 보상**: 공물 활용 시 인장/매혹석 타겟 보상
- **권장 배치 슬롯**: 2~4

## 자원 목표별 체인 예시

### A. 신화 유니크 노림수 체인

1. 둥지 보스 — 신화 유니크 직접 시도
2. 헬타이드 — 보스 트로피 누적
3. 헬타이드 — 트리 중간 경로 반복
4. 균열 — 마지막 보스 처치로 추가 보상
5. 둥지 보스 — 두 번째 시도

### B. 빌드 가루 풀 충원 체인

1. 악몽 던전 — 문양 XP + Raw 가루
2. 헬타이드 — 가루 광역 수급
3. 지옥의 무리 — Burning Aether + 가루
4. 균열 — Pure Dust 시도
5. 악몽 던전 — 문양 XP 마무리

### C. 매혹석/인장 빌드업 체인

1. 헬타이드 — 매혹석 다수
2. 쿠라스트 지하도시 — 인장 타겟
3. 헬타이드 — 셋 매혹석 추가 시도
4. 쿠라스트 지하도시 — 공물 사용
5. 둥지 보스 — 마무리 보상

## FAQ

**Q. 같은 활동을 5단계에 모두 넣을 수 있나요?**
A. 가능합니다. 다만 동일 활동 반복은 전쟁 상자 보상이 단조로워질 수 있어, 자원 다변화를 위해 최소 2종 이상 섞는 것이 일반적입니다.

**Q. 인장이 부족한데 자동 생성된다고 하는데 실제로 어떻게 동작하나요?**
A. 체인 시작 시 필요한 인장/열쇠가 없으면 시스템이 임시 인장을 생성해 입장에 사용합니다. 다만 인장의 변형 옵션은 기본값이거나 제한됩니다.
