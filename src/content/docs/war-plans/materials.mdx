## 사용처

전쟁 계획 시스템에서 다음 용도로 사용됩니다.

1. <span class="kw-gold">**전쟁 계획 활동 강화**</span> — 보상 풀 확장 + 활동 트리 노드 활성화
2. <span class="kw-gold">**전리품 함 잠금해제**</span> — 함 보상 풀의 강화 + 함 등급 상향
3. <span class="kw-rare">**상위 활동 입장권**</span> — 일부 활동은 코론 재료 소모로 시작
4. <span class="kw-mythic">**시즌 보스 소환 보조**</span> — 메피스토의 메아리 등 최종 보스방 준비

> ⚠ 활동별로 요구하는 코론 재료가 다릅니다. 게임 내 활동 메뉴에서 정확한 소모량 확인 후 진행하세요.

## 파밍 최적 경로

### 출처 (공통)

세 재료 모두 **전쟁 계획 보상 활동**에서 획득합니다. 활동마다 떨어지는 비율이 다릅니다.

| 활동 카테고리 | 잘 떨어지는 재료 |
|-------------|---------------|
| <span class="kw-blood">**헬타이드·우두머리**</span> | <span class="kw-blood">코론의 피</span> (혈화 모티프 — 지옥 활동 위주) |
| <span class="kw-bone">**악몽 던전·소굴 우두머리**</span> | <span class="kw-bone">코론의 육신</span> (돌 모티프 — 던전 위주) |
| <span class="kw-magic">**나락·지하도시**</span> | <span class="kw-magic">코론의 눈물</span> (수정 모티프 — 균열·지하 위주) |

> ⚠ 위 매핑은 시각 모티프 기반 추정입니다. 정확한 드랍 활동은 시즌 진행 중 확인 권장.

### 누적 권장 시점

| 시즌 단계 | 권장 활동 | 비고 |
|---------|--------|------|
| <span class="kw-bone">**1주차**</span> | 우선순위 낮음 — 전쟁 계획 자체 잠금해제 후 시작 | 캠페인·시즌 등급 우선 |
| <span class="kw-rare">**2-3주차**</span> | 전쟁 계획 활동 일상 진행 — 3종 균형 누적 | 함 전리품과 함께 자연 누적 |
| <span class="kw-gold">**4주차+ (빌드 완성)**</span> | 부족한 종류 집중 파밍 | 신화 추첨·시즌 보스 단계 준비 |

## 자원 효율 팁

:::tip[효율 극대화]
- <span class="kw-gold">**전쟁 계획 일상 루틴 따라가기**</span> — 자연스럽게 3종 균형 누적. 전쟁 계획 [일상 루틴](/war-plans/daily-routine/) 가이드 참고
- <span class="kw-rare">**3종 균형 유지**</span> — 한 종류만 부족하면 진행 막힘. 부족한 재료의 출처 활동 집중
- <span class="kw-bone">**함 전리품 보상과 함께**</span> — 코론 재료 파밍하면서 동시에 8종 태고의 가루도 누적됨 → 일석이조
- <span class="kw-blood">**시즌 보스방 준비**</span> — 최종 보스방 입장 전에 3종 모두 최소 5개씩 비축 권장
- <span class="kw-mythic">**거래 불가**</span> — 모든 코론 재료는 계정 귀속. 직접 파밍만 가능
:::

## FAQ

**Q. 코론은 누구인가요?**
A. 시즌 13 증오의 군주 스토리에서 등장하는 시즌 보스 또는 NPC. 시즌마다 핵심 인물의 이름을 따 재료 명명 (예: 시즌 12 = 다른 이름 시리즈).

**Q. 시즌이 끝나면 코론 재료는 어떻게 되나요?**
A. 시즌 13 종료 시 코론 재료는 **시즌 영역에서만 유효**합니다. 시즌 14 출시 시 새로운 시즌 재료로 교체되며, 사용하지 않은 코론 재료는 영원 서버 이전 시 자동 처분 또는 변환 (시즌별 정책 다름 — 패치 노트 확인).

**Q. 시즌 영역에서 영원으로 가져갈 수 있나요?**
A. **불가능**. 시즌 한정 재료입니다. 시즌 기간 내에 모두 사용해야 효율적입니다.

**Q. 거래소에서 살 수 있나요?**
A. **불가능**. 계정 귀속. 직접 파밍만 가능.

**Q. 어느 활동에서 코론의 피가 가장 잘 떨어지나요?**
A. 시즌 진행 중 검증된 데이터를 본 사이트에서 추가 업데이트 예정. 일반적으로 헬타이드·시즌 보스 처치 활동에서 빈출 경향. 정확한 드랍 활동은 게임 내 활동 보상 풀 표기 확인.
