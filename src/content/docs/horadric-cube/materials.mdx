:::tip[게임 내 공식 명칭 기준]
본 문서의 명칭과 설명은 **게임 내 클라이언트 툴팁 원문**을 기반으로 작성되었습니다. fan-translation 이 아닌 인-게임 공식 한국어 표기를 그대로 사용합니다.
:::

### 3분 안에 핵심만

- **9종 재료** — 활성 가루 7종 + 호라드림 수액 1종 + 공명하는 가루 1종 (미활성)
- **공통 출처 3대장**: <span class="kw-rare">전쟁 계획의 함 전리품</span>, <span class="kw-rare">속삭임의 나무 보관함 보상</span>, <span class="kw-bone">정예 괴물</span>
- **호라드림 수액**: 부적·문장 분해 시 획득 (제작 1순위 자원)
- **희귀도별 우선순위**: 마법 → 희귀 → 전설 → 고유 등급 가루
- **파밍 최적**: 전쟁 계획 5단계 (함 전리품) + 속삭임 누적 반납

</div>

:::caution[현재 게임 내 미확정 — 데이터마이닝 단계]

- **사용 레시피 미공개** — 사용자 측: "cant find a recipe that uses it". 큐브 UI 어떤 변환에서도 입력으로 노출되지 않음.
- **이미지 미확보** — 실제 인벤토리 진입 사례가 거의 없어 한국 클라이언트 툴팁 스크린샷이 존재하지 않습니다. 본 문서에 사진을 첨부하지 않은 이유.

## FAQ

**Q. "Primordial Dust" 의 한국 공식 명칭이 무엇인가요?**
A. **태고의 가루**. 인-게임 클라이언트의 정확한 표기이며 wowhead 한국 페이지에서도 확인 가능합니다.

**Q. 미가공 태고의 가루가 너무 많이 쌓이는데 어떻게 활용?**
A. 거의 모든 큐브 레시피의 부재료로 들어가므로 자연히 소진됩니다. 시즌 초중반엔 풍족하지만 빌드 완성 후엔 부족해질 수 있으니 무리하게 분해하지 마세요.

**Q. 가루 등급이 높을수록 더 좋은 건가요?**
A. **사용처가 다릅니다**. 고급 가루 (향상된/조율된) 는 양이 적지만 고유 아이템·신화 추첨에 필수. 기본 가루 (미가공) 는 양이 많이 필요한 부재료. 등급별로 따로 누적해야 합니다.

**Q. 영원 캐릭터에서도 같은 가루가 떨어지나요?**
A. 모든 가루는 시즌/영원 공통이며, 시즌 종료 시 영원으로 자동 이관됩니다.

**Q. 가루를 거래소에서 살 수 있나요?**
A. **불가능**. 모든 태고의 가루는 거래 불가 (계정 귀속). 직접 파밍만 가능.

**Q. 9번 공명하는 태고의 가루는 왜 이미지가 없나요?**
A. **현재 게임 내 인벤토리 진입 사례가 거의 없습니다.** wowhead 데이터마이닝(item ID 2530723) 으로 존재만 확인되었고, Blizzard 공식 포럼에서 "드랍해도 보관함에 안 들어가는 버그" 가 보고되었습니다. 한국 클라이언트 툴팁 스크린샷이 확보되는 시점에 추가합니다.

**Q. 신화 매혹석은 호라드림의 함으로 제작할 수 있나요?**
A. **불가능합니다.** Unique Charm 레시피는 Ancestral Unique gear 만 입력으로 받고, Mythic Unique gear 는 제외됩니다. 현재 확인된 신화 매혹석 [영벌의 후예](/mythic-items/heir-of-perdition/) 는 **전쟁 계획 완주 보상** 으로만 드랍됩니다 (Icy Veins 2026-04 보고).
