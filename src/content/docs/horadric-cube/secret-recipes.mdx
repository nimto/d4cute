## 한 줄 요약

> 일부 레시피는 큐브 UI 목록에 바로 보이지 않고, 특정 재료를 같이 넣어야 활성화됩니다. 본 페이지는 커뮤니티에서 검증 단계가 끝난 항목만 다룹니다. **미검증 항목은 명시적으로 표기**합니다.

## 잠금해제

- 호라드림 큐브가 잠금해제되어 있어야 합니다.
- 일부 비밀 레시피는 **고난도(Torment) 단계** 또는 **전쟁 계획 사령부 활성화** 이후에만 작동합니다.

## 검증된 비밀 레시피

### 1. 매혹석 → 매혹석 변환 (다른 셋으로)

| 항목 | 값 |
|------|----|
| 입력 | 셋 매혹석 1개 + Refined Dust 25 + 일반 매혹석 2개 |
| 산출 | **다른 셋**의 매혹석 1개 (무작위) |
| 비고 | 일반 "셋 매혹석 리롤"과 달리, 셋 자체가 바뀜 |

### 2. 보스 트로피 → 신화 유니크 추첨

| 항목 | 값 |
|------|----|
| 입력 | 보스 트로피 1개 + Pure Dust 1 + Attuned Dust 5 |
| 산출 | 해당 보스 풀의 **신화 유니크 1개** |
| 비고 | 일반 유니크 추첨 대비 비용 ~5배, 결과 풀이 신화로 한정됨 |

### 3. 메아리의 흔적 통합

| 항목 | 값 |
|------|----|
| 입력 | 메아리의 흔적 10개 |
| 산출 | 메피스토의 메아리 입장권 1개 |
| 비고 | 종료된 시즌 활동의 보상권을 모아 보스 입장권으로 변환 |

## 보고된 미검증 레시피

> 아래 항목은 커뮤니티에서 보고되었으나 본 사이트가 공식/세미오피셜 출처로 확인하지 못한 것들입니다. **시도 전 자원 비용을 고려하세요.**

- 4종 색이 모두 다른 보석을 같은 등급으로 넣어 **무지개 보석(Rainbow Gem)** 을 추첨한다는 설 — 미확인
- 룬 4종(Bac+Igni+Tam+Yul)을 한 번에 넣어 **숨겨진 의식 룬** 을 만든다는 설 — 미확인
- 특정 유니크 + 보스 트로피 + Tuning Prism으로 **신화 유니크 결정 산출** 이 된다는 설 — 미확인

## 자원 효율 팁

- 비밀 레시피는 일반 레시피보다 **자원 비용이 평균 2~5배** 높습니다. 빌드의 막바지에 잉여 자원이 있을 때만 시도하세요.
- 신화 유니크 추첨은 동일 보스 풀의 신화 유니크 풀이 좁을수록 효율이 올라갑니다. 어떤 보스 풀에 어떤 신화 유니크가 있는지 사전 조사 권장.

## FAQ

**Q. 미검증 레시피를 시도했다가 자원만 날렸습니다. 환불은?**
A. 환불 불가합니다. 본 페이지의 "검증된" 항목 외에는 시도 전 충분히 정보를 확인해주세요.

**Q. 새 비밀 레시피가 발견되면 어떻게 반영되나요?**
A. 본 사이트 GitHub 저장소에 Issue 또는 PR로 출처 링크와 함께 제보해주시면 검토 후 갱신합니다.
