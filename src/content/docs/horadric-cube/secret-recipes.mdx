## 한 줄 요약

> 일부 레시피는 큐브 UI 목록에 바로 보이지 않고, 특정 재료를 같이 넣어야 활성화됩니다. 본 페이지는 커뮤니티에서 검증 단계가 끝난 항목만 다룹니다. **미검증 항목은 명시적으로 표기**합니다.

## 용어 한 줄 정리

처음 보는 용어가 많은 분들을 위해 본 페이지에서 사용되는 단어를 먼저 정리합니다.

| 용어 | 의미 |
|------|------|
| <span class="kw-gold">**비밀 레시피**</span> | 큐브 UI 메뉴에 안 보임. 특정 재료 조합을 직접 넣어야 작동 |
| <span class="kw-gold">**보스 풀**</span> | 특정 보스가 떨어뜨리는 <span class="kw-mythic">신화 고유</span> 후보군. 보스마다 떨어뜨리는 종류가 다름 |
| <span class="kw-gold">**보스 트로피**</span> | 우두머리(보스) 처치 후 얻는 부산물 (예: 살아있는 강철·악의 심장 등 보스별 고유 재료) |
| <span class="kw-mythic">**신화 고유**</span> | 디아블로4 최상위 등급 고유 아이템 (총 13종, 시즌13 기준) |
| <span class="kw-rare">**순수한 가루 (Pure Dust)**</span> | 호라드림 큐브의 가장 비싼 변성 자원 |
| <span class="kw-rare">**조율된 가루 (Attuned Dust)**</span> | 변성 결과 풀을 좁히는 카테고리 지향 자원 |
| <span class="kw-rare">**정제된 가루 (Refined Dust)**</span> | 일반 변성 작업의 표준 자원 |
| <span class="kw-bone">**부적(Charm) / 셋 부적**</span> | 시즌13 신규 아이템 (영물 인벤토리). 셋 부적은 추가 셋 효과 부여 |
| <span class="kw-blood">**메아리의 흔적**</span> | <span class="kw-blood">메아리치는 증오</span> 활동 보상권. 10개 모아 메피스토 보스방 입장권으로 변환 |
| <span class="kw-blood">**메피스토의 메아리**</span> | 시즌13 최종 보스 메피스토와 1:1 대전하는 보스방 |

## 잠금해제

- 호라드림 큐브가 잠금해제되어 있어야 합니다.
- 일부 비밀 레시피는 **고난도(Torment) 단계** 또는 **전쟁 계획 메뉴 활성화** 이후에만 작동합니다.

## 보고된 미검증 레시피

> 아래 항목은 커뮤니티에서 보고되었으나 본 사이트가 공식/세미오피셜 출처로 확인하지 못한 것들입니다. <span class="kw-danger">**시도 전 자원 비용을 고려하세요.**</span>

- 4종 색이 모두 다른 보석을 같은 등급으로 넣어 **무지개 보석(Rainbow Gem)** 을 추첨한다는 설 — <span class="kw-danger">미확인</span>
- 룬 4종(Bac+Igni+Tam+Yul)을 한 번에 넣어 **숨겨진 의식 룬** 을 만든다는 설 — <span class="kw-danger">미확인</span>
- 특정 고유 + 보스 트로피 + 조율의 프리즘으로 **신화 고유 결정 산출** 이 된다는 설 — <span class="kw-danger">미확인</span>

## 자원 효율 팁

### 한 줄 정리

> <span class="kw-gold">**비밀 레시피 = 일반 경로보다 비쌈 + 결과가 더 좁음**</span>. 빌드 막바지 잉여 자원에서만 사용.

### 비밀 레시피 vs 일반 경로 비용 비교

| 목적 | 일반 경로 | 비밀 레시피 | 비용 차이 |
|------|---------|-----------|---------|
| <span class="kw-mythic">**신화 고유 1회 추첨**</span> | 우두머리 처치 (드랍 확률 약 1.5%) 또는 큐브 제작 (반짝이는 벼락불 2개 + 룬) | <span class="kw-blood">보스 트로피 1</span> + <span class="kw-rare">순수한 가루 1</span> + <span class="kw-rare">조율된 가루 5</span> | <span class="kw-blood">**약 5배**</span> |
| <span class="kw-bone">**셋 부적 변경**</span> | 동일 셋 다시 파밍 (수 시간) | <span class="kw-bone">셋 부적 1</span> + 일반 부적 2 + <span class="kw-rare">정제된 가루 25</span> | <span class="kw-bone">**약 3배**</span> |
| <span class="kw-blood">**메피스토 보스방 입장**</span> | 메아리치는 증오 활동 1회 (10-15분) | <span class="kw-blood">메아리의 흔적 10개</span> 통합 | <span class="kw-bone">**약 2배**</span> |

### "보스 풀이 좁을수록 효율 ↑" 가 무슨 뜻?

보스마다 떨어뜨리는 <span class="kw-mythic">신화 고유</span> 후보가 **다릅니다**. 후보가 적으면 원하는 것이 나올 확률이 자연히 높아집니다.

| 추첨 방법 | 후보 풀 크기 (예시) | 원하는 1종이 나올 확률 |
|---------|-----------------|--------------------|
| <span class="kw-mythic">**일반 신화 큐브 제작**</span> (반짝이는 벼락불 2개, 미지정) | <span class="kw-mythic">13종</span> | <span class="kw-bone">약 7.7%</span> |
| <span class="kw-blood">**중간 풀 보스 트로피**</span> (예: 안다리엘) | <span class="kw-blood">5-6종</span> | <span class="kw-gold">약 16-20%</span> |
| <span class="kw-blood">**좁은 풀 보스 트로피**</span> (예: 메피스토 전용 신화) | <span class="kw-blood">2-3종</span> | <span class="kw-gold">**약 33-50%**</span> |

> ⚠ 위 풀 크기는 시즌13 기준 추정치입니다. 정확한 보스별 신화 풀은 [신화 고유 페이지](/horadric-cube/mythic-items/) 참고.

### 추천 사용 시점 — 시즌 단계별

| 시즌 단계 | 비밀 레시피 사용 | 이유 |
|---------|---------------|------|
| <span class="kw-bone">**초반 (1-2주)**</span> | <span class="kw-danger">❌ 사용 비추</span> | 기본 자원 (가루·룬·부적) 부터 누적이 우선 |
| <span class="kw-rare">**중반 (3-5주)**</span> | <span class="kw-rare">⚠ 선택적 사용</span> | 셋 부적 변환만 시도. 신화 추첨은 잉여 자원 있을 때만 |
| <span class="kw-gold">**후반 (빌드 완성 후)**</span> | <span class="kw-gold">✅ 적극 활용</span> | <span class="kw-mythic">신화 고유</span> 추첨 + 흔적 통합. 잉여 자원 소진 단계 |

### 자원 누적 우선순위

비밀 레시피를 시도하기 전에 다음 재료가 충분히 모여 있어야 합니다.

1. <span class="kw-rare">**순수한 가루(Pure Dust)**</span> 최소 5개 이상 — 명품화 + 신화 추첨에 동시 사용
2. <span class="kw-rare">**조율된 가루(Attuned Dust)**</span> 최소 25개 이상 — 신화 추첨 5회 분
3. <span class="kw-blood">**보스 트로피**</span> 최소 3개 — 노림 보스 풀에 맞게 비축
4. <span class="kw-blood">**메아리의 흔적**</span> 10개 이상 누적 — 보스방 입장권 변환용

## FAQ

**Q. 미검증 레시피를 시도했다가 자원만 날렸습니다. 환불은?**
A. 환불 불가합니다. 본 페이지의 "검증된" 항목 외에는 시도 전 충분히 정보를 확인해주세요.

**Q. "신화 고유" 와 "신화 유니크" 가 같은 건가요?**
A. 같은 아이템입니다. <span class="kw-gold">**신화 고유**</span>가 디아블로4 공식 한국어 명칭이며, "신화 유니크"는 영문 Mythic Unique 직역의 비공식 표현입니다. 본 페이지는 공식 명칭을 사용합니다.

**Q. 보스 트로피는 어떻게 얻나요?**
A. 시즌13 우두머리 처치 시 부산물로 드랍됩니다. 보스별로 종류가 다르며 (예: 메피스토 = 살아있는 강철, 안다리엘 = 악의 심장 등) 보스방 재입장 또는 다른 보스 소환 재료로도 사용됩니다.

**Q. 새 비밀 레시피가 발견되면 어떻게 반영되나요?**
A. 본 사이트 GitHub 저장소에 Issue 또는 PR로 출처 링크와 함께 제보해주시면 검토 후 갱신합니다.
