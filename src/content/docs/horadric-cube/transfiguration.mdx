## 한 줄 요약

> 빌드에 가장 자주 사용되는 카테고리입니다. <span class="kw-gold">어픽스 추가</span> → <span class="kw-gold">카테고리 재롤(Chaotic)</span> → <span class="kw-gold">같은 카테고리 재롤(Focused)</span> → <span class="kw-gold">재제련(Transfigure)</span> 순으로 자원 효율과 결과의 안정도가 올라갑니다.

<div class="summary-box">
### 3분 안에 핵심만

- **목적**: 아이템 어픽스를 <span class="kw-gold">빌드 방향</span>으로 다듬기.
- **위험 1순위**: <span class="kw-blood">무질서의 프리즘</span> — 한 번 쓰면 <span class="kw-danger">되돌릴 수 없음</span>. 빌드 확정 직후에만.
- **자원 효율 1순위**: 빌드 카테고리에 맞는 <span class="kw-gold">카테고리 지향 분광경</span> 우선 사용.
- **목걸이 예외**: <span class="kw-bone">재제련 후에도 추가 수정 가능</span>. 클레의 분광경 권장.

</div>

## 큐브 카테고리 한눈에

호라드림 큐브는 3개의 대분류를 가집니다. <span class="kw-gold">장비 변경(Equipment Modification)</span>이 본 페이지가 다루는 어픽스 수정 영역이며, 나머지는 별도 페이지에서 다룹니다. 아이콘을 클릭하면 큰 이미지로 확인할 수 있습니다.

**장비 변경 하위 옵션** (좌측 이미지 펼친 상태):

- <span class="kw-gold">속성 추가</span> — 어픽스 추가 (Add Affix). 무작위 어픽스 1개 신규 부여.
- <span class="kw-gold">혼돈의 재설정</span> (Chaotic Reroll) — 카테고리 단위 재롤. 빌드 카테고리 확보의 1단계.
- <span class="kw-gold">집중적인 재설정</span> (Focused Reroll) — 같은 카테고리 내 종류·수치 미세 조정.
- <span class="kw-bone">속성 제거</span> (Remove Affix) — 무작위 어픽스 1개 제거.
- <span class="kw-blood">아이템 변신</span> (Transfigure Item) — 카테고리 잠금 + 강력 변형. <span class="kw-danger">무질서의 프리즘</span>으로 마감.
- <span class="kw-unique">고유 능력 재설정</span> (Unique Power Reroll) — 태고 유니크의 고정 옵션 수치 재추첨.

## 잠금해제

호라드림 큐브 잠금해제와 동시에 사용 가능합니다. 다만 일부 작업은 <span class="kw-unique">태고(Ancestral)</span> 등급 아이템에서만 의미가 있으므로 <span class="kw-gold">고난도 1단계</span> 이상부터 본격 활용합니다.

## 자원 절약 팁

:::tip[효율적 자원 사용]
- <span class="kw-gold">**어픽스 추가는 보조 수단**</span> — 어떤 어픽스가 붙을지 모르므로 정 안 풀릴 때 마지막에 시도합니다.
- <span class="kw-bone">**목걸이는 클레의 분광경**</span> — 목걸이만 재제련 후에도 추가 수정 가능. 다른 부위와 자원 우선순위를 분리하세요.
- <span class="kw-gold">**카테고리 지향 분광경 우선**</span> — 빌드 카테고리가 확정됐다면 <span class="kw-rare">다채로운(범용)</span>보다 <span class="kw-offensive">공격</span>/<span class="kw-defensive">방어</span>/<span class="kw-utility">실용</span>/<span class="kw-abundance">풍족</span> 중 맞는 카테고리로 직행하는 게 자원 효율이 가장 좋습니다.
:::

:::danger[무질서의 프리즘 — 사용 직전 체크리스트]
한 번 사용하면 <span class="kw-danger">**더 이상 수정 불가**</span>. 빌드가 <span class="kw-gold">완전히 확정</span>된 뒤에만 사용하세요.

- ☐ 빌드 어픽스가 모두 원하는 카테고리에 있는가?
- ☐ 핵심 능력치 수치가 만족스러운 범위인가?
- ☐ 동일 부위의 더 좋은 아이템이 곧 들어올 가능성이 낮은가?

위 3가지가 모두 ✅ 일 때만 진행합니다.
:::

## FAQ

**Q. 재제련에 일반 조율 프리즘을 안 쓰면 결과가 어떻게 되나요?**
A. 프리즘 없이도 재제련은 가능하지만, 결과가 <span class="kw-danger">완전 무작위</span>입니다. 자원 효율이 낮습니다.

**Q. 한 아이템에 어픽스 추가를 여러 번 할 수 있나요?**
A. 아이템 등급별 어픽스 슬롯 상한까지만 가능합니다. 슬롯이 꽉 찬 아이템에는 작용하지 않습니다.

**Q. 무질서의 프리즘 적용 후 실수를 깨달았습니다. 되돌릴 수 있나요?**
A. <span class="kw-danger">**되돌릴 수 없습니다.**</span> 동일 부위의 새 아이템을 구해 처음부터 다시 작업해야 합니다.

**Q. 엔트로피의 조율의 "100% 속성 변경 불가" 는 무슨 의미인가요?**
A. 변성 결과를 <span class="kw-gold">카테고리 단위로 영구 고정</span>시켜 더 이상 수정할 수 없게 만든다는 뜻입니다. 빌드 어픽스가 <span class="kw-blood">완벽히 확정</span>된 직후에만 사용하세요.
