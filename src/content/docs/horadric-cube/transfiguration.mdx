## 한 줄 요약

> 빌드에 가장 자주 사용되는 카테고리입니다. **어픽스 추가 → 카테고리 재롤(Chaotic) → 같은 카테고리 재롤(Focused) → 재제련(Transfigure)** 순으로 자원 효율과 결과의 안정도가 올라갑니다.

## 큐브 카테고리 한눈에

호라드림 큐브는 3개의 대분류를 가집니다. **장비 변경(Equipment Modification)** 이 본 페이지가 다루는 어픽스 수정 영역이며, 나머지는 별도 페이지에서 다룹니다. 아이콘을 클릭하면 큰 이미지로 확인할 수 있습니다.

**장비 변경 하위 옵션** (좌측 이미지 펼친 상태):

- **속성 추가** — 어픽스 추가 (Add Affix). 무작위 어픽스 1개 신규 부여.
- **혼돈의 재설정** (Chaotic Reroll) — 카테고리 단위 재롤. 빌드 카테고리 확보의 1단계.
- **집중적인 재설정** (Focused Reroll) — 같은 카테고리 내 종류·수치 미세 조정.
- **속성 제거** (Remove Affix) — 무작위 어픽스 1개 제거.
- **아이템 변신** (Transfigure Item) — 카테고리 잠금 + 강력 변형. 무질서의 프리즘으로 마감.
- **고유 능력 재설정** (Unique Power Reroll) — 태고 유니크의 고정 옵션 수치 재추첨.

## 잠금해제

호라드림 큐브 잠금해제와 동시에 사용 가능합니다. 다만 일부 작업은 **태고(Ancestral)** 등급 아이템에서만 의미가 있으므로 고난도 1단계 이상부터 본격 활용합니다.

## 조율 분광경 자원 카탈로그

레시피 입력에 들어가는 **조율의 분광경(Tuning Dust)** 들입니다. 등급이 올라갈수록 결과 제어력이 높아지며, 같은 1000 가격대라도 **방향성** 이 다릅니다(공격/방어/실용/풍족/다채). 아이콘을 클릭하면 인-게임 툴팁 원본을 확대해서 확인할 수 있습니다.

## 권장 작업 순서

호라드림 큐브의 자원 효율을 살리는 일반적인 순서:

1. **기본 어픽스 확보** — 빌드 어픽스가 절반 이상 박힌 아이템을 골라옵니다.
2. **카테고리 재롤(Chaotic)** — 원치 않는 어픽스 카테고리를 모두 빌드 카테고리로 교체. → **엔트로피 분광경 [542]** 또는 카테고리 지향 분광경 사용.
3. **같은 카테고리 재롤(Focused)** — 카테고리는 맞지만 종류가 어긋난 어픽스를 미세 조정. → **숙련자의 조율 [788]** 또는 **다채로운 [1000]**.
4. **재제련(Transfigure)** — 최종 어픽스를 카테고리 잠금 + 강화. **무질서의 프리즘** 으로 마무리.
5. **유니크 파워 재롤** — 유니크 슬롯이라면 수치 최적화를 마지막에 시도.

## 자원 절약 팁

- **어픽스 추가는 보조 수단** — 어떤 어픽스가 붙을지 모르므로 정 안 풀릴 때 마지막에 시도합니다.
- **무질서의 프리즘은 결정 직전에만** — 한 번 사용하면 더 이상 수정 불가하므로, 빌드가 확정된 뒤에 사용합니다.
- **목걸이는 클레의 분광경 [369]** — 목걸이만 재제련 후에도 추가 수정이 가능합니다. 다른 부위와 자원 우선순위를 분리하세요.
- **1000 가격대 카테고리 분광경 우선** — 빌드 카테고리가 확정됐다면 다채로운(범용)보다 공격/방어/실용/풍족 중 맞는 카테고리로 직행하는 게 자원 효율이 가장 좋습니다.

## FAQ

**Q. 재제련에 일반 조율 프리즘을 안 쓰면 결과가 어떻게 되나요?**
A. 프리즘 없이도 재제련은 가능하지만, 결과가 완전 무작위입니다. 자원 효율이 낮습니다.

**Q. 한 아이템에 어픽스 추가를 여러 번 할 수 있나요?**
A. 아이템 등급별 어픽스 슬롯 상한까지만 가능합니다. 슬롯이 꽉 찬 아이템에는 작용하지 않습니다.

**Q. 무질서의 프리즘 적용 후 실수를 깨달았습니다. 되돌릴 수 있나요?**
A. 되돌릴 수 없습니다. 동일 부위의 새 아이템을 구해 처음부터 다시 작업해야 합니다.

**Q. 엔트로피의 조율 [542] 의 "100% 속성 변경 불가" 는 무슨 의미인가요?**
A. 변성 결과를 카테고리 단위로 영구 고정시켜 더 이상 수정할 수 없게 만든다는 뜻입니다. 빌드 어픽스가 완벽히 확정된 직후에만 사용하세요.
