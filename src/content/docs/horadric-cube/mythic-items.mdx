## 재료 정리

### 공통 재료 — 반짝이는 벼락불 (Sparkling Thunderbolt / Resplendent Spark)

- 신화 1개 specific 제작: <span class="kw-mythic">**2개 필요**</span>
- 무작위 신화 교환: <span class="kw-mythic">**2개**</span>
- 주요 출처:
  - <span class="kw-gold">**Belial (의식의 둥지)**</span> 처치 보상
  - <span class="kw-gold">**호라드림 금고실(Strongroom)**</span> — 신화 보장 노드
  - <span class="kw-gold">**비밀 레시피 — 보스 트로피 추첨**</span> 부산물
  - <span class="kw-gold">**전쟁 계획 함**</span> 최종 보상 (확률)

### 룬 재료

각 신화는 의식/기원 룬 3종 × 6개씩 요구. 룬 종류는 [룬 제작 페이지](/horadric-cube/runes/) 의 33개 카탈로그 참고.

#### 룬 → 신화 매핑 (빠른 조회)

같은 룬을 요구하는 신화들 — 동시 노림 시 룬 분산. 빌드 1개 결정 → 그 신화에 필요한 룬만 집중 파밍 권장:

| 자주 쓰이는 룬 | 사용 신화 |
|---|---|
| <span class="kw-legendary">**탐**</span> (의식 전설) | 안다리엘의 두개골 · 한마비 |
| <span class="kw-rare">**녹**</span> (의식 희귀) | 거짓된 죽음의 수의 · 궤멸자 |
| <span class="kw-rare">**잔**</span> (의식 희귀) | 안다리엘의 두개골 |
| <span class="kw-magic">**쳄**</span> (의식 마법) | 별 없는 하늘의 반지 |
| <span class="kw-legendary">**에옴**</span> (기원 전설) | 할리퀸 관모 |
| <span class="kw-rare">**라크**</span> (기원 희귀) | 할리퀸 관모 |
| <span class="kw-magic">**테브**</span> (기원 마법) | 박살난 맹세 |

## 자원 절약 팁

:::tip[효율적 신화 파밍]
- <span class="kw-gold">**룬 우선순위 1개 신화 결정**</span> — 빌드 가이드(Maxroll/Mobalytics) 에서 추천 신화 1개 픽 → 그 룬만 집중 파밍.
- <span class="kw-bone">**Belial + 금고실 병행**</span> — 반짝이는 벼락불 안정 수급. Belial 이 모든 보스 중 신화 드랍률 최고.
- <span class="kw-gold">**거래소 활용**</span> — 룬 시세는 메타 빌드 의존도에 따라 천차만별. <span class="kw-legendary">비메타 전설 룬</span> 직접 매수가 효율적.
- <span class="kw-danger">**조급한 제작 금지**</span> — 신화는 한 번 제작하면 환불 불가. 빌드 확정 후에만.
:::

## FAQ

**Q. 시즌13 의 진짜 "신규" 신화는 몇 개인가요?**
A. <span class="kw-mythic">정의의 검 엘드루인 1종</span> 이 새로 추가됐습니다. 추가로 신화 매혹석 카테고리에 <span class="kw-mythic">왕족 위엄의 인장(Seal of Royal Grandeur)</span> 이 매혹석 슬롯용으로 신설됐지만, 본 페이지의 13종 장비 신화에는 포함되지 않습니다. 기존 신화들도 패치로 효과 재조정 + 새 어픽스 (취약 피해 배수, 지속 피해 배수 등) 반영됐습니다.

**Q. In-Geom 은 새로운 신화인가요?**
A. <span class="kw-danger">아닙니다.</span> 일부 기사에서 "In-Geom 이 돌아온다" 라고 표현되지만, 실제로는 D3 의 In-Geom 효과를 가진 신화로 <span class="kw-mythic">엘드루인</span> 이 등장한 것입니다. In-Geom 이라는 이름의 별도 신화는 없습니다.

**Q. 제작한 신화 아이템도 거래 가능한가요?**
A. <span class="kw-danger">큐브에서 제작한 신화는 계정 귀속</span> 입니다. 거래소 판매 불가. 단, 드랍받은 신화 중 일부는 거래 가능합니다.

**Q. 룬을 거래소에서 사면 제작비가 얼마나 드나요?**
A. 룬 18개 (3종 × 6) + 반짝이는 벼락불 2개 + 5,000 골드. 룬 시세는 종류·메타에 따라 다양. 비메타 전설 룬을 노리면 총 비용 크게 절감.

**Q. 클래스별 사용 제한이 있나요?**
A. 일부 신화는 클래스 제한이 있습니다. 예: <span class="kw-mythic">네세켐</span> 은 <span class="kw-unique">정수술사 전용</span>, <span class="kw-mythic">아하바리온</span> 은 <span class="kw-unique">원소술사·드루이드</span> 만 장착 가능. 나머지는 대부분 범용.
