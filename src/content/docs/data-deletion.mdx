**최종 수정일: 2026-05-17**

본 사이트(d4cute)는 자체 데이터베이스를 운영하지 않으므로, 사이트 내부에 저장된 사용자 데이터가 없습니다. Giscus 댓글 위젯을 통해 작성된 댓글은 본 저장소의 **GitHub Discussions** (https://github.com/nimto/d4cute/discussions) 에 저장됩니다. 이 문서는 해당 데이터의 삭제 절차를 안내합니다.

## 1. 본인 댓글 직접 삭제 (가장 빠름)

1. 본 사이트의 해당 페이지 하단 댓글 위젯에서 본인이 작성한 댓글을 찾습니다.
2. 댓글 우측 상단 메뉴(`...`) → **Delete** 클릭.
3. 즉시 GitHub Discussions 에서 해당 댓글이 삭제됩니다.

## 2. GitHub Discussions 에서 직접 관리

1. https://github.com/nimto/d4cute/discussions 접속 (GitHub 로그인 필요).
2. 본인이 작성한 댓글이 있는 Discussion 항목을 검색.
3. 각 댓글 우측 `...` 메뉴 → **Delete**.
4. 본인 작성 댓글은 본인 권한으로 즉시 삭제 가능합니다.

## 3. 운영자에게 일괄 삭제 요청

본인 명의의 댓글이지만 직접 접근이 어렵거나(계정 분실 등) 일괄 삭제가 필요한 경우, 아래 정보를 포함하여 운영자에게 이메일로 요청해주세요.

- 수신처: **nimtos@gmail.com**
- 제목 예: `[d4cute] 댓글 삭제 요청`
- 본문 포함 항목:
  - GitHub 사용자명 또는 프로필 URL
  - 삭제 대상 페이지 URL (전체/일부)
  - 본인 확인을 위한 추가 정보(선택)

요청 접수 후 영업일 기준 7일 이내 처리하며, 처리 결과를 회신합니다. 운영자는 본 저장소 owner 권한으로 Discussions 의 모든 댓글에 대한 삭제·숨김·잠금 권한을 가집니다.

## 4. 사이트 액세스 로그 (GitHub Pages)

GitHub Pages 의 기본 액세스 로그(IP, User-Agent 등)는 GitHub 이 보관하며, 운영자는 해당 로그에 접근할 수 없습니다. 삭제 또는 열람 요청은 GitHub 측에 직접 요청해야 합니다.

- GitHub Privacy Inquiries: https://github.com/contact/privacy
