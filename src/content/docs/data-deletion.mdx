**최종 수정일: 2026-05-17**

본 사이트(d4cute)는 자체 데이터베이스를 운영하지 않으므로, 사이트 내부에 저장된 사용자 데이터가 없습니다. 다만 Facebook 댓글 위젯을 통해 작성된 댓글은 Meta 의 서버에 보관됩니다. 이 문서는 해당 데이터의 삭제 절차를 안내합니다.

## 1. 본인 댓글 직접 삭제 (가장 빠름)

1. 본 사이트의 해당 페이지 하단 댓글 위젯에서 본인이 작성한 댓글을 찾습니다.
2. 댓글 우측 상단 메뉴(`...`) → **삭제** 클릭.
3. 즉시 Facebook 서버에서 해당 댓글이 삭제됩니다.

## 2. Facebook 계정 활동 로그에서 일괄 관리

1. Facebook 로그인 → 설정 → **활동 로그**(Activity Log) 이동.
2. 좌측 필터에서 "내 댓글" 또는 "다른 사람의 게시물에 단 댓글" 선택.
3. 도메인 또는 키워드로 `nimto.github.io` 검색.
4. 각 항목 우측 메뉴에서 **삭제** 선택.

## 3. 운영자에게 일괄 삭제 요청

본인 명의의 댓글이지만 직접 접근이 어렵거나(계정 분실 등) 일괄 삭제가 필요한 경우, 아래 정보를 포함하여 운영자에게 이메일로 요청해주세요.

- 수신처: **nimtos@gmail.com**
- 제목 예: `[d4cute] 댓글 삭제 요청`
- 본문 포함 항목:
  - Facebook 프로필 URL 또는 표시 이름
  - 삭제 대상 페이지 URL (전체/일부)
  - 본인 확인을 위한 추가 정보(선택)

요청 접수 후 영업일 기준 7일 이내 처리하며, 처리 결과를 회신합니다. 단 Facebook API 제약상 운영자가 사용자의 댓글을 직접 삭제할 수 없는 경우, 해당 페이지에서 댓글 위젯을 비활성화하거나 Facebook 신고 절차를 안내해드립니다.

## 4. 사이트 액세스 로그 (GitHub Pages)

GitHub Pages 의 기본 액세스 로그(IP, User-Agent 등)는 GitHub 이 보관하며, 운영자는 해당 로그에 접근할 수 없습니다. 삭제 또는 열람 요청은 GitHub 측에 직접 요청해야 합니다.

- GitHub Privacy Inquiries: https://github.com/contact/privacy
