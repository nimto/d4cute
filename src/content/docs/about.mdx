## 사이트 소개

본 사이트는 디아블로 IV **시즌13(심판의 시즌)** 과 **증오의 군주(Lord of Hatred)** 확장팩을 한국어로 정리한 비공식 가이드입니다. 한국어 유저가 영문 가이드를 일일이 번역해 읽는 부담을 줄이고, 공식 패치노트와 한국 공식 표기를 한 곳에서 확인할 수 있도록 만들어졌습니다.

## 운영 원칙

1. **공식 우선** — 모든 게임 데이터는 블리자드 공식 패치노트 또는 신뢰도 높은 가이드 사이트(Icy-Veins, Maxroll, Mobalytics, Wowhead, Fextralife Wiki 등)를 1차 출처로 사용합니다.
2. **한국어 재구성** — 영문 자료를 자동 번역으로 옮기지 않고, 한국어 사용자가 자연스럽게 읽을 수 있도록 재구성합니다.
3. **출처 명시** — 모든 토픽 페이지 하단에 참고 자료 목록을 게시합니다.
4. **빠른 업데이트** — 핫픽스/패치가 적용되면 영향받는 페이지의 `마지막 업데이트` 날짜를 갱신합니다.

## 기술 스택

- **프레임워크**: Astro 6.x + Starlight
- **콘텐츠**: MDX (Markdown + JSX)
- **검색**: Pagefind (한국어 인덱싱)
- **댓글**: Facebook Comments Plugin (페이지별 분리)
- **배포**: GitHub Actions → GitHub Pages
- **언어**: 한국어 기본

## 면책

- 이 사이트는 **비공식 팬 가이드**입니다. 게임 내 정보는 블리자드 공식 패치노트가 우선합니다.
- Diablo IV, Diablo IV: Lord of Hatred, Season of Reckoning 등의 명칭과 로고는 © Blizzard Entertainment의 상표입니다.
- 본 사이트는 어떤 게임 내 이미지/아트워크도 직접 호스팅하지 않습니다. 모든 시각 자료는 자체 작성 또는 공식 공개 자료의 출처 명시 후 링크 형태로만 사용됩니다.
- 본 사이트 콘텐츠의 정확성에 최선을 다하지만, 정보 누락이나 패치 적용 지연으로 인한 결과의 책임은 사용자에게 있습니다.
