**최종 수정일: 2026-05-17**

이 문서는 비공식 팬 사이트 d4cute(이하 "본 사이트")가 방문자의 개인정보를 어떻게 처리하는지 안내합니다. 본 사이트는 비영리 정적 사이트이며, 직접적으로 개인정보를 수집·저장하지 않습니다.

## 1. 수집 항목

본 사이트의 코드(Astro Starlight) 자체는 어떠한 개인정보도 수집하지 않습니다. 다만 아래 외부 서비스가 페이지 내에서 동작합니다.

| 서비스 | 수집 주체 | 항목 | 목적 |
|--------|---------|------|------|
| GitHub Pages | GitHub, Inc. | IP, User-Agent, 접속 시각(액세스 로그) | 정적 파일 전송, 남용 방지 |
| Facebook 댓글 위젯 | Meta Platforms, Inc. | Facebook 로그인 시 프로필명·아바타·작성 댓글 | 댓글 게시·표시 |

각 항목은 해당 서비스 제공자의 개인정보처리방침을 따릅니다.

- GitHub Pages: https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement
- Facebook(Meta): https://www.facebook.com/privacy/policy/

## 2. 쿠키

본 사이트는 자체 쿠키를 설정하지 않습니다. Facebook 댓글 위젯이 로드되는 경우 Meta 가 자체적으로 쿠키를 설정할 수 있으며, 이는 Meta 의 정책을 따릅니다.

## 3. 분석 도구

본 사이트는 Google Analytics 등 별도의 분석 도구를 사용하지 않습니다.

## 4. 광고

본 사이트는 광고를 게재하지 않습니다.

## 5. 제3자 제공

본 사이트는 직접 수집하는 개인정보가 없으므로 제3자에게 제공할 정보도 없습니다.

## 6. 보관 기간

본 사이트는 데이터를 보관하지 않습니다. Facebook 으로 작성된 댓글은 Meta 의 보관 정책을 따릅니다.

## 7. 정보 주체의 권리 및 삭제 요청

작성한 Facebook 댓글의 삭제·수정은 Facebook 계정에서 직접 수행할 수 있으며, 본 사이트 운영자에게 일괄 삭제 요청을 보낼 수도 있습니다. 자세한 절차는 [데이터 삭제 안내](/data-deletion/) 페이지를 참고합니다.
