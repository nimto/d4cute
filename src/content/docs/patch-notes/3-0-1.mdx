## 한 줄 요약

> **2026년 4월 27일** — 확장팩 출시와 같은 날 적용된 첫 패치. 보석 전면 재설계, 첨탑(Tower)이 **장인의 첨탑(Artificer's Tower)** 으로 변경, 시각 효과/접근성 개선.

## 출시 정보

| 항목 | 값 |
|------|----|
| 패치 버전 | 3.0.1 |
| 출시일 | 2026년 4월 27일 |
| 시즌 | 시즌13 — 심판의 시즌 |

## 주요 변경점

### 보석 재설계

- 무기 슬롯의 모든 보석 효과가 **곱연산(multiplicative) 데미지 보너스**로 전환
- **에메랄드**: 치명타 데미지 → **독 데미지**로 변경
- 자세한 시스템 가이드: [보석](/gems/)

### 장인의 첨탑 (Artificer's Tower)

- 기존 **첨탑(The Tower)** 이 **장인의 첨탑(The Artificer's Tower)** 으로 명칭 변경
- 보상 풀 강화 + 리더보드 기능 추가
- 향후 리더보드 마일스톤 보상 별도 발표 예정

### 시각 / 접근성 개선

- 방어막(Shielded) · 반사(Reprisal) 군주의 시각 효과 강화
- 반사 데미지가 투사체 형태로 표시
- **색맹 보조 옵션** 추가 — 색각 이상 사용자용 색상 보정

### 기타

- 출시 직후 발견된 여러 버그 핫픽스 — 빌드 진행 차단 이슈 우선

## 본 사이트의 영향

3.0.1 보석 재설계로 인해 본 사이트의 [보석 슬롯별 효과](/gems/slots/) 페이지가 시즌13 기준으로 작성되어 있습니다. 본편 시즌의 보석 효과와 다르므로 주의하세요.

## FAQ

**Q. 3.0.1 적용 전에 사용 중이던 에메랄드는 어떻게 되나요?**
A. 자동으로 새 효과(독 데미지)로 갱신됩니다. 별도 작업이 필요 없습니다.

**Q. 장인의 첨탑 리더보드는 언제 시작되나요?**
A. 본 사이트 확인 시점 기준 첨탑 자체는 활성화되어 있으며, 시즌 리더보드 마일스톤 보상이 별도 일정으로 공개되었습니다. 정확한 일자는 인게임 공지를 확인하세요.
