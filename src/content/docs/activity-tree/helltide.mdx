## 잠금해제

헬타이드 1회 완주 시 자동 등록. 후반 노드는 고난도(토먼트) 단계 상승으로 잠금해제됩니다.

## 7 포인트 최적 분배 — 사냥 목적별

| 목적 | 분배 | 핵심 노드 | 활용 시점 |
|------|------|---------|----------|
| <span class="kw-gold">**유니크 노림 (표준)**</span> | <span class="kw-rare">중앙 4 + 우측 3</span> | Duriels Suffering · Bounty Hunter | <span class="kw-gold">메타 표준 — 디폴트 선택</span> |
| <span class="kw-rare">**보스 트로피 누적**</span> | <span class="kw-rare">중앙 7</span> | Hellwyrm 매복 · Pang of Duriel | <span class="kw-rare">[큐브 합성](/horadric-cube/amalgamation/) 노림수</span> |
| <span class="kw-bone">**레벨링 (1-70)**</span> | <span class="kw-bone">우측 4 + 좌측 3</span> | Bounty Hunter · Profane Mindcage | <span class="kw-bone">시더/경험치/잊혀진 영혼 안정 수급</span> |
| <span class="kw-blood">**고숙련 도전**</span> | <span class="kw-blood">좌측 7</span> | Profane Mindcage 자동 + 적 강도 ↑ | <span class="kw-blood">빌드 완성 + 토먼트 5+ 안정 클리어</span> |

## 경로별 상세

### 중앙 경로 (Middle Path) — <span class="kw-gold">표준 추천</span>

- **핵심**: <span class="kw-rare">**Duriels Suffering**</span> — 무작위 유니크 드랍 트리거
- **부가**: <span class="kw-rare">Hellwyrm 매복</span> 트리거 — 매복 시 <span class="kw-gold">구더기(Maggots) + Pang of Duriel</span> 등장
- **인용 (Mobalytics)**: *"Maggots drop considerable amounts of experience and Boss Trophies which can be turned in at the Horadric Cube for Uniques."*

### 우측 경로 (Right Path) — <span class="kw-rare">편의 + 자원 보존</span>

- <span class="kw-rare">**Bounty Hunter**</span> — 깜부기(Cinder) 추가 보상
- 사망 시 시더 손실 방지
- 100시더 모을 때마다 추가 10시더 자동 획득
- 666시더로 구입 가능한 <span class="kw-gold">**지옥의 보상(Hell's Prize) 상자**</span> 추가

### 좌측 경로 (Left Path) — 도전형

- <span class="kw-blood">**Profane Mindcage**</span> 자동 적용 — 적 강도 상승, 시더·경험치·드롭 증가
- 빌드가 본격 광역에 진입한 후에만 효율

## 권장 선택 — 빌드 상태 매트릭스

| 캐릭터 상태 | 권장 분배 | 환불 타이밍 |
|------------|---------|-----------|
| 시즌 초 1-70 레벨링 | <span class="kw-bone">우측 4 + 좌측 3</span> | 토먼트 진입 후 |
| 토먼트 1-4 아이템 셋업 | <span class="kw-gold">중앙 4 + 우측 3 (표준)</span> | 보스 트로피 충분히 모인 후 |
| 토먼트 5+ 신화 노림 | <span class="kw-rare">중앙 7</span> | 빌드 완성 후 좌측 7 |
| 엔드 빌드 완성 | <span class="kw-blood">좌측 7</span> | 시즌 종료 시 |

## 자원 효율 팁

:::tip[효율 극대화]
- <span class="kw-gold">**중앙 경로 + War Plans 헬타이드 슬롯 2회**</span> — 같은 시간에 가장 많은 보스 트로피 누적
- <span class="kw-bone">**트리 포인트 회수**</span> — 시즌 중반에 우측에서 중간으로 재분배가 흔함. 환불 골드 비용 항상 여유 있게
- <span class="kw-mythic">**잊혀진 영혼 부족**</span> 시 우측 Bounty Hunter 최우선
:::

:::caution[지옥의 보상 상자 비용]
666시더는 상당히 큰 비용. <span class="kw-blood">시더 모자라면 보상함 포기</span> 더 효율적. 우측 경로 분배 후에만 시도.
:::

## FAQ

**Q. 헬윔 매복은 트리 포인트 없이도 자동 발생하나요?**
A. 매복 자체는 가능하지만, 중간 경로 포인트가 누적될수록 매복 빈도와 보상이 크게 증가합니다.

**Q. 보스 트로피 잉여분이 너무 많으면 어디에 쓰나요?**
A. [호라드림 큐브 합성](/horadric-cube/amalgamation/)에서 유니크 풀 추첨에 사용하거나, [비밀 레시피](/horadric-cube/secret-recipes/)의 신화 유니크 추첨에 투입합니다.

**Q. War Plans 안에서 헬타이드를 안 돌고 단독 진입하면 손해인가요?**
A. <span class="kw-blood">네 — War Plans 안에서 활동 경험치 25배</span>. 항상 War Plans 슬롯에 헬타이드 포함시켜 진행.

**Q. 시즌 초 어떤 노드부터 찍나요?**
A. <span class="kw-bone">우측 Bounty Hunter 1포</span> → <span class="kw-bone">우측 시더 보존 1포</span> → 활동 누적되면 중앙 Duriels Suffering 로 전환.
