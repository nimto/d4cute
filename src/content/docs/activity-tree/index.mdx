## 한 줄 요약

> 헬타이드 · 악몽 던전 · 쿠라스트 지하도시 · 균열(나락) · 둥지 보스 · 지옥불 군세 · 호라드림 금고실 — 각 활동에 <span class="kw-gold">**활동 스킬 트리(Activity Skill Tree)**</span> 가 생겨, 활동의 보상과 도전 난이도를 직접 조절합니다. **속삭임의 나무** 는 별도 시스템으로 다른 활동과 동시 진행 가능.

<div class="summary-box">
### 3분 안에 핵심만

- **S 티어 활동** (최우선): <span class="kw-gold">헬타이드</span>, <span class="kw-gold">쿠라스트 지하도시</span>
- **A 티어** (고우선): <span class="kw-rare">둥지 보스</span>, <span class="kw-rare">악몽 던전</span>

- **D 티어**: <span class="kw-blood">지옥불 군세</span> — 보상 빈약 (시즌13 너프)
- <span class="kw-danger">**위험 함정**</span>: 지하도시 트리의 <span class="kw-blood">'시련' 노드</span> + <span class="kw-blood">공물 상자 함정</span> — [지하도시 페이지](/activity-tree/undercity/) 의 경고 섹션 필독

</div>

## 잠금해제

각 활동을 1회 이상 완주하면 해당 활동의 트리가 전쟁 계획 메뉴에 등록됩니다. 포인트는 활동 완주 시 자동 누적됩니다.

## 시즌13 활동 티어 (Mobalytics 메타 기준)

| 등급 | 활동 | 핵심 보상 | 권장 이유 |
|------|------|----------|----------|
| <span class="kw-gold">**S**</span> | <span class="kw-gold">헬타이드</span> | 경험치 · 둥지 열쇠 · 잊힌 영혼 | 시즌 전체 가장 효율적 자원원 |
| <span class="kw-gold">**S**</span> | <span class="kw-gold">쿠라스트 지하도시</span> | 공물 시스템으로 타겟 파밍 | 매혹석·인장 노림 최강 |
| <span class="kw-rare">**A**</span> | <span class="kw-rare">소굴 우두머리</span> | 신화·유니크 풀 | 가장 빠른 활동 (수 초 소요) |
| <span class="kw-rare">**A**</span> | <span class="kw-rare">악몽 던전</span> | 문양 XP · 신화 풀 | 빠른 완주 + 높은 잠재 보상 |
| <span class="kw-bone">**B**</span> | <span class="kw-bone">나락 (균열)</span> | 문양 XP | 너프 후 문양 위주로 축소 |
| <span class="kw-blood">**D**</span> | <span class="kw-blood">지옥불 군세</span> | Burning Aether · 보스 트로피 | 시간 대비 보상 빈약. 메타 빌드 외에는 비추 |
| - | <span class="kw-bone">속삭임의 나무</span> | 보관함 보상 | 다른 활동과 **병행 가능** (전쟁 계획 노드 X) |

> 출처: [Mobalytics — War Plans Guide](https://mobalytics.gg/diablo-4/guides/warplans-guide). 메타는 패치마다 변동합니다.

## 트리 핵심 구조 (공통 패턴)

| 위치 | 일반적 역할 |
|------|----------|
| <span class="kw-offensive">**좌측 가지**</span> | 난도 상승·도전 (Challenge) — 클리어 시 보상 배수 증가 |
| <span class="kw-gold">**중앙 가지**</span> | 핵심 보상 강화 (보스 트로피·반짝이는 벼락불·신화 풀) |
| <span class="kw-defensive">**우측 가지**</span> | 편의·경험치 (이동속도·드랍률·XP 보너스) |

> 빌드가 강하면 좌측(난도) → 클리어 가능한 만큼만. 빌드가 약하면 우측(편의) → 안정 클리어 우선.

## 포인트 획득 방식

- 활동 완주 시 자동 누적
- 동일 활동을 여러 번 완주할수록 포인트가 점진적으로 누적되며, 트리마다 상한이 있습니다.
- 일부 트리는 <span class="kw-gold">고난도 단계</span> 가 올라가야 후반 노드가 잠금해제됩니다.

## 위험 함정 — 반드시 알아둘 것

:::danger[지하도시 시련 / 공물 상자]
- <span class="kw-blood">**지하도시 좌측 트리의 '시련' 노드**</span> — 클리어 시간 단축 요구. 빌드가 약하면 진행 불가 → 포인트 낭비
- <span class="kw-danger">**공물 상자 함정**</span> — 지하도시 내 일부 노드 활성화 시 상자가 등장. **실수로 클릭하면 사용 중인 공물 인장이 그 자리에서 소모**됨. 매혹석/인장 타겟 파밍이 망함
- 자세한 안내는 [지하도시 트리 페이지](/activity-tree/undercity/) 필독
:::

:::caution[지옥불 군세 분배 주의]
시즌13 너프 후 보상이 시간 대비 가장 빈약 (D 티어). 메타 빌드에서 Burning Aether 가 핵심이 아닌 한 포인트 분배 비추.
:::

## FAQ

**Q. 트리 포인트는 캐릭터별인가요?**
A. 캐릭터별로 분리되어 있습니다. 신규 캐릭터는 새로 분배해야 합니다.

**Q. 한번 찍은 포인트를 회수할 수 있나요?**
A. 일부 트리는 재설정(reset) 비용을 지불해 회수가 가능합니다. 비용은 전쟁 계획 메뉴에서 확인하세요.

**Q. 7개 트리 다 만점 만들 필요 있나요?**
A. <span class="kw-blood">없습니다.</span> 빌드와 메타 활동만 우선 분배. D 티어(지옥불 군세) 는 빌드가 의존하지 않는 한 후순위.

**Q. 캡처가 7개 트리인데 헬타이드는 어디 있나요?**
A. 사용자 캡처에서는 <span class="kw-bone">'지옥물결'</span> 이라는 표기가 헬타이드 카테고리 트리일 가능성이 있습니다. 정확한 한국명 표기는 게임 클라이언트가 최우선. 추가 캡처 제공 시 갱신.
