## 잠금해제

균열 1회 클리어 시 등록. 사망 페널티가 없어 진입 비용이 매우 낮습니다.

## 경로별 상세

### 좌측 경로 (Left Path) — <span class="kw-rare">메타 1순위</span>

- <span class="kw-rare">**Chorons Haste**</span> — 클리어 시 <span class="kw-gold">글리프 업그레이드 확률 +1</span>
- <span class="kw-rare">**Heart of Stone**</span> — 진행 오브 등장 → 클리어 시간 단축

### 중앙 경로 (Middle Path) — 마스터워킹 자원

- 층 클리어 시 마스터워킹 재료 추가 산출
- 각 층 종료 보상함의 가루/프리즘 비율 상승
- 후반 층 처치 시 Pure Dust 드롭률 소폭 상승

### 우측 경로 (Right Path) — 편의

- 시간 보너스 (남은 시간에 따른 추가 보상)
- 글리프 보상 강화

## 자원 효율 팁

:::tip[효율 극대화]
- <span class="kw-gold">**사망 페널티 없음**</span> → 빌드 약해도 도전 가능. 시즌 초 빌드 점검용으로 적합
- <span class="kw-rare">**글리프 만렙 가속**</span> — Chorons Haste 우선 분배가 모든 빌드의 글리프 21 만렙 도달을 1주일 이상 단축
- <span class="kw-bone">**마스터워킹 가장 안정**</span> — 마스터워킹 자원은 나락이 가장 안정적. 빌드 완성 직전 단계에 분배

## FAQ

**Q. 5층은 한 번에 클리어해야 하나요?**
A. 진입한 시도 안에서만 연속 가능합니다. 시도가 종료되면 다음 시도부터 1층부터 다시 시작합니다.

**Q. 나락 후반 층은 어느 정도 빌드가 필요한가요?**
A. 빌드별 편차가 크지만, 일반적으로 본 빌드 어픽스 50% 이상에 매혹석 핵심 셋이 갖춰지면 후반 층 도전이 가능합니다.

**Q. Chorons Haste 의 글리프 업그레이드 +1 은 어떻게 작동하나요?**
A. 나락 클리어 보상으로 받는 <span class="kw-gold">글리프 업그레이드 시도 횟수에 +1</span> 추가. 즉 같은 1회 클리어로 평소 1번 굴리던 글리프를 2번 굴림. 만렙 도달 시간 사실상 절반.

**Q. 사망 페널티가 없는데 좌측 도전 노드 찍어도 되나요?**
A. <span class="kw-blood">사망 페널티 없음 ≠ 클리어 보장</span>. 좌측 도전 노드는 시간 제한 추가 → 클리어 자체 어려워짐. 빌드 완성 후에만 분배.
