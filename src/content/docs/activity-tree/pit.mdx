## 한 줄 요약

> 확장팩에서 균열은 **5층 구조**로 개편되고 **사망 페널티가 제거**되었습니다. 트리는 마스터워킹 자원 강화 + 층 보상 강화 + 도전 변형 추가로 분기됩니다.

## 잠금해제

균열 1회 클리어 시 등록. 사망 페널티가 없어 진입 비용이 매우 낮습니다.

## 주요 경로

| 경로 | 효과 |
|------|------|
| 마스터워킹 자원 | 층 클리어 시 마스터워킹 재료 추가 산출 |
| 층 보상 | 각 층 종료 보상함의 가루/프리즘 비율 상승 |
| 도전 변형 | 시간 제한 / 추가 변이 적 등의 변형 옵션 추가 |
| Pure Dust 시도 | 후반 층 처치 시 Pure Dust 드롭률 소폭 상승 |

## 사용 팁

- **사망 페널티 없음** → 빌드가 약해도 도전 가능. 시즌 초 빌드 점검용으로 적합.
- **마스터워킹 자원**이 가장 안정적으로 떨어지는 활동이므로, 빌드 완성 직전 단계에 집중적으로 분배하는 것이 효율적입니다.
- 균열은 짧고 자주 돌 수 있어 [전쟁 계획](/war-plans/) 5단계 중 마지막 슬롯의 단골입니다.

## FAQ

**Q. 5층은 한 번에 클리어해야 하나요?**
A. 진입한 시도 안에서만 연속 가능합니다. 시도가 종료되면 다음 시도부터 1층부터 다시 시작합니다.

**Q. 균열 후반 층은 어느 정도 빌드가 필요한가요?**
A. 빌드별 편차가 크지만, 일반적으로 본 빌드 어픽스 50% 이상에 매혹석 핵심 셋이 갖춰지면 후반 층 도전이 가능합니다.
