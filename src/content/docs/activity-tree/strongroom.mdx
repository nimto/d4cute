## 한 줄 요약

> <span class="kw-rare">**호라드림 금고실**</span> — 증오의 군주 신규 활동 던전. <span class="kw-mythic">조율 프리즘 + 반짝이는 벼락불</span> 의 가장 안정적 공급처. 7 포인트 분배는 <span class="kw-rare">중앙(가루 보상) + 우측(희귀 산출)</span> 우선.

<div class="summary-box">
### 3분 안에 핵심만

- **활동 성격**: 큐브 자원 풀 보강 전용 — 골드·일반 아이템 보상은 부수적
- **핵심 보상**: <span class="kw-mythic">반짝이는 벼락불</span> · <span class="kw-rare">Volatile/Pure 가루</span> · <span class="kw-rare">조율 프리즘</span> · 신화 인장 풀
- **메타 분배**: <span class="kw-rare">중앙 4 (가루 보상) + 우측 3 (희귀 산출)</span>
- **시점**: 신화 아이템 제작 직전, 또는 변성/재제련 자원 부족 시 집중

</div>

## 잠금해제

확장팩 캠페인 클리어 후 테미스(Temis)에서 활동 입구가 마킹됩니다.

## 7 포인트 최적 분배 — 자원 목적별

| 목적 | 분배 | 핵심 노드 |
|------|------|---------|
| <span class="kw-rare">**큐브 자원 종합 (표준)**</span> | <span class="kw-rare">중앙 4 + 우측 3</span> | 가루 상위 비율 ↑ · 프리즘 산출 ↑ |
| <span class="kw-mythic">**반짝이는 벼락불 노림**</span> | <span class="kw-mythic">우측 5 + 중앙 2</span> | 신화 인장 풀 · 희귀 산출 |
| <span class="kw-gold">**빠른 클리어**</span> | <span class="kw-gold">좌측 4 + 우측 3</span> | 시간 단축 보너스 · 추가 보상 |

## 경로별 상세

### 중앙 경로 (Middle Path) — <span class="kw-rare">가루 보상 표준</span>

- 종료 보상함의 상위 가루(Volatile / Pure / Refined) 비율 상승
- 일반 가루 → 상위 가루 등업 확률

### 우측 경로 (Right Path) — 희귀 산출

- 조율 프리즘 산출 빈도 ↑
- 보스 트로피 추가
- <span class="kw-mythic">**신화 인장 풀 확률 소폭 상승**</span>

### 좌측 경로 (Left Path) — 시간 압박

- 시간 단축 보너스 — 빠른 클리어 시 추가 보상
- 클리어 속도 빠른 빌드에 적합

## 자원 효율 팁

:::tip[큐브 자원 안정 공급]
- <span class="kw-mythic">**반짝이는 벼락불 부족**</span> — 신화 아이템 제작 직전이라면 우측 5포 + Belial 처치 병행
- <span class="kw-rare">**조율 프리즘 부족**</span> — 변성/재제련 자원 부족 시 가장 안정적 공급처
- <span class="kw-bone">**전쟁 계획 마지막 슬롯 단골**</span> — 짧고 자주 돌 수 있음. War Plans 5단계 마지막에 배치
:::

## FAQ

**Q. 일반 던전 보상과 차이가 있나요?**
A. 호라드림 큐브 관련 자원(가루·프리즘·반짝이는 벼락불)의 비중이 큰 활동. 일반 던전이 골드·아이템 중심인 반면, 금고실은 <span class="kw-gold">큐브 자원 풀 보강 전용</span>.

**Q. 반짝이는 벼락불 1개당 평균 몇 회 클리어해야 나오나요?**
A. 우측 노드 분배 시 평균 5-10회 클리어당 1개. Belial 보상에 비하면 낮지만 안정성 ↑.

**Q. 금고실 트리만 만렙 찍어도 신화 제작 가능한가요?**
A. 가능. 단 룬 18개 (3종 × 6) + 5,000 골드도 같이 필요. [신화 아이템 카탈로그](/horadric-cube/mythic-items/) 참고.

**Q. 신규 캐릭터도 바로 도전 가능한가요?**
A. 확장팩 캠페인 클리어 후 가능. 캠페인 미클리어 캐릭터는 입구 자체가 안 보임.
