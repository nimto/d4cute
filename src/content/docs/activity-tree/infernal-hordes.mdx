## 한 줄 요약

> 지옥의 무리 트리는 **Burning Aether 누적 효율**과 **마지막 보스 강화/회복**으로 분기됩니다. 빌드의 광역 처치력을 시험하기 좋은 활동입니다.

## 잠금해제

지옥의 무리 1회 완주 시 등록.

## 주요 경로

| 경로 | 효과 |
|------|------|
| Aether 누적 | 웨이브당 Burning Aether 산출 증가 |
| 보스 강화 | 마지막 보스의 보상 풀 강화 |
| 회복 | 웨이브 사이 체력/리소스 회복 추가 |
| 도전 변형 | 추가 변형 옵션 — 성공 시 Aether 배수 |

## 사용 팁

- **광역 빌드와 궁합 최고** — 웨이브 사이 처치 속도가 곧 Aether 누적량이 됩니다.
- 빌드의 자원 부족 문제가 있다면 회복 경로로 균형을 잡습니다.

## FAQ

**Q. Burning Aether는 어디에 사용하나요?**
A. 활동 종료 후 NPC 상점에서 가루·매혹석·인장 등으로 교환 가능합니다.
