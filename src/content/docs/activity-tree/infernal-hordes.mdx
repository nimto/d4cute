시즌13 패치로 보상이 시간 대비 가장 빈약해졌습니다. **빌드가 Burning Aether 에 의존하지 않는 한 다른 활동 (헬타이드 · 지하도시 · 소굴 우두머리) 우선 분배** 가 효율적입니다. 시즌 도전이 끝나면 환불해서 다른 트리로 재분배 권장.
:::

## 잠금해제

지옥의 무리 1회 완주 시 등록.

## 경로별 상세

### 좌측 경로 (Left Path) — Aether 누적

- 웨이브당 Burning Aether 산출 증가
- 도전 변형 옵션 — 성공 시 Aether 배수

### 중앙 경로 (Middle Path) — 보스 강화

- 마지막 보스 보상 풀 강화
- 보스 트로피 추가 산출

### 우측 경로 (Right Path) — 안정성

- 웨이브 사이 체력/자원 회복
- 빌드 자원 부족 시 균형 잡기용

## 자원 효율 팁

:::tip[D 티어 활용법]
- <span class="kw-blood">**일반 빌드는 분배 0**</span> — 다른 활동 분배 후 잉여 골드 환불 비용 가능 시에만
- <span class="kw-bone">**시즌 도전 강제 시**</span> — 좌측 3포만. 도전 클리어 후 환불
- <span class="kw-rare">**메아리치는 증오(Echoing Hatred)**</span> — 끝없는 웨이브. 빌드 한계 테스트용. 보상은 부수적
- <span class="kw-bone">**광역 빌드 시너지**</span> — 웨이브 사이 처치 속도 = Aether 누적량. 광역 약한 빌드는 더더욱 비추
:::

## FAQ

**Q. Burning Aether 는 어디에 사용하나요?**
A. 활동 종료 후 NPC 상점에서 가루·매혹석·인장 등으로 교환 가능. 단 교환 효율이 다른 활동의 직접 드랍보다 낮음.

**Q. 메아리치는 증오는 일반 지옥불 군세와 다른가요?**
A. 같은 활동의 확장 모드. 종료 조건 없이 적이 끝없이 강해짐. 빌드 한계 테스트 + 도전 기록 용도.

**Q. D 티어인데 왜 트리가 존재하나요?**
A. 시즌 시작 직후엔 A-B 티어로 출발 → 패치 너프로 D 로 강등. 향후 메타 변경 패치로 재평가 가능성 항상 있음. <span class="kw-bone">시즌 후반 갱신 확인 권장</span>.

**Q. 환불 비용은 얼마나 드나요?**
A. 사령부 UI 에서 확인. 일반적으로 시즌 초 골드 풍부할 때 환불은 부담 없음.
