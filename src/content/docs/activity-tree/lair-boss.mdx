## 한 줄 요약

> 확장팩에서 일반/특급 둥지 열쇠가 **단일 열쇠로 통합**되었고, 처치 보스의 종류에 따라 풀이 결정됩니다. 트리는 유니크 풀 강화 + 추가 트로피 + 도전 변형으로 구성됩니다.

## 잠금해제

둥지 보스 1회 처치 시 등록. 통합 열쇠는 캠페인 종료 후 자동 적용.

## 주요 경로

| 경로 | 효과 |
|------|------|
| 유니크 풀 강화 | 처치 시 보스 풀 유니크의 드롭률 상승 |
| 추가 트로피 | 보스 트로피 산출 빈도 +확률 |
| 도전 변형 | 시간 제한/체력 캡 변형 추가 — 성공 시 보상 배수 |
| 신화 풀 잠금해제 | 후반 노드 — 신화 유니크 드롭 시도 가능 |

## 사용 팁

- **시즌 후반에 가장 큰 가치** — 신화 풀 노드는 매혹석/매혹석 셋이 갖춰진 뒤에 활용도가 극대화됩니다.
- 전쟁 계획 5단계에 둥지 보스를 2회 넣어 트로피 + 유니크 노림수 사이클을 짜는 것이 일반적.

## FAQ

**Q. 통합 열쇠 도입 전에 모아둔 특급 열쇠는 어떻게 되나요?**
A. 호환 가능합니다. 통합 시스템에서 동일한 보스 풀 접근권으로 사용됩니다.

**Q. 신화 유니크는 트리 노드 없이도 드롭되나요?**
A. 가능하지만 빈도가 매우 낮습니다. 시즌 중후반의 트리 분배에서 신화 풀 노드 우선이 권장됩니다.
