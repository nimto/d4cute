## 잠금해제

둥지 보스 1회 처치 시 등록. 통합 열쇠는 캠페인 종료 후 자동 적용.

## 7 포인트 최적 분배

| 목적 | 분배 | 핵심 노드 | 활용 시점 |
|------|------|---------|----------|
| <span class="kw-rare">**유니크 + 보스 체인 (표준)**</span> | <span class="kw-rare">중앙 4 + 좌측 3</span> | Escalating Nemesis · Hoard Chest | <span class="kw-rare">메타 표준</span> |
| <span class="kw-mythic">**신화 노림**</span> | <span class="kw-mythic">중앙 5 + 우측 2</span> | 신화 풀 + 보스 트로피 | <span class="kw-mythic">매혹석 셋 완성 후</span> |
| <span class="kw-bone">**보스 트로피 누적**</span> | <span class="kw-bone">우측 7</span> | 추가 트로피 · 빈도 ↑ | <span class="kw-bone">[합성](/horadric-cube/amalgamation/) 자원 확보</span> |

## 경로별 상세

### 중앙 경로 (Middle Path) — <span class="kw-rare">메타 표준</span>

- <span class="kw-rare">**Escalating Nemesis**</span> — 보스 처치 후 추가 보스 체인 등장
- 신화 풀 잠금해제 (후반 노드)

### 좌측 경로 (Left Path) — 유니크 드랍률

- <span class="kw-rare">**Hoard Chest**</span> — 유니크 드랍률 ↑ 추가 상자
- 풀별 유니크 등장 빈도 증가

### 우측 경로 (Right Path) — 트로피 + 편의

- 보스 트로피 산출 빈도 + 확률 증가
- 도전 변형 (시간 제한 / 체력 캡)

## 권장 선택 — 진행 단계별

| 캐릭터 단계 | 권장 분배 |
|------------|---------|
| 시즌 초 (매혹석 0) | <span class="kw-bone">우측 7</span> (트로피 누적 → 합성용) |

## 자원 효율 팁

:::tip[효율 극대화]
- <span class="kw-gold">**가장 빠른 활동**</span> — War Plans 5단계에 2회 넣어 트로피 + 유니크 사이클
- <span class="kw-rare">**Escalating Nemesis 체인**</span> — 1회 열쇠로 2-3번 처치 효과 → 자원 효율 2-3배
- <span class="kw-mythic">**신화 풀 시즌 후반 가치 극대화**</span> — 매혹석 핵심 셋이 갖춰진 뒤에 신화 풀 노드 분배가 효율
:::

## FAQ

**Q. 통합 열쇠 도입 전에 모아둔 특급 열쇠는 어떻게 되나요?**
A. 호환 가능합니다. 통합 시스템에서 동일한 보스 풀 접근권으로 사용됩니다.

**Q. 신화 유니크는 트리 노드 없이도 드롭되나요?**
A. 가능하지만 빈도가 매우 낮습니다. 시즌 중후반 신화 풀 노드 우선 분배 권장.

**Q. Escalating Nemesis 의 체인은 무한히 발생하나요?**
A. 노드 단계별로 체인 횟수 상한. 일반적으로 2-3번 체인. 노드 만렙 시 추가 체인 가능.

**Q. 신화 노림 시 어느 보스가 가장 효율인가요?**
A. <span class="kw-mythic">Belial (의식의 둥지)</span> 가 신화 드랍률 최고. War Plans 슬롯에 Belial 우선 배치.
