## 한 줄 요약

> 시즌13 활동 스킬 트리 — 각 활동에 <span class="kw-gold">7 포인트</span> 만 투자 가능. 활동 완주마다 누적 + <span class="kw-bone">골드 환불</span> 가능. 사냥법(레벨업/아이템/신화 노림) 마다 최적 분배가 다릅니다.

### 3분 안에 핵심만 (디아4 처음 접하는 유저용)

- 포인트 획득: 각 활동을 완주할 때마다 그 트리의 포인트가 자동 누적. 최대 7
- 환불: 골드를 내면 포인트 회수 가능 — 빌드 바뀌면 재분배
- 시즌 초 추천: <span class="kw-gold">지옥물결(헬타이드)</span> + <span class="kw-gold">나락(균열)</span> 부터 — 가장 자주 도는 활동

## 활용법 + 초보 가이드

### 디아4 처음 접하는 유저

1. <span class="kw-gold">캐릭터 60렙 + 토먼트 1 진입</span> 까지는 본 사이트의 [빠른 시작](/quickstart/) 가이드 우선
2. <span class="kw-gold">War Plans 시스템 잠금해제 (60렙+)</span> 후 본 페이지로 돌아옴
3. <span class="kw-rare">위 "빌드 목적별 추천 분배" decision-flow 따라</span> 단계적 분배
4. <span class="kw-bone">환불은 자유롭게</span> — 진행 단계마다 재분배 가정. 시즌 메타 패치 변동 항상 있음

### 분배 결정 체크리스트

- ☐ 내 캐릭터 레벨은? (1-70 = 레벨링, 70 = 토먼트 진행)
- ☐ 현재 토먼트 단계는? (1-3 = 아이템 셋업, 4-6 = 신화 노림, 7+ = 엔드 글리프)
- ☐ 메타 빌드 따라가는 중인가? (Maxroll/Mobalytics 빌드 가이드의 활동 추천 우선)
- ☐ 환불 골드 여유 있는가? (없으면 보수적 분배 우선)

## 갱신 계획

- 사용자가 트리별 노드 캡처 제공 시 한국명 매핑 추가
- 노드별 효과 요약 텍스트 (한국명 매핑 후 단계적 추가)
- 빌드 가이드 추천 노드 표시 (Maxroll/Mobalytics 메타 빌드 기준)
