## 활용법

1. **빠른 훑기** — 위 갤러리에서 트리별로 노드 아이콘 스캔
2. **노드 효과 확인** — 아이콘 클릭 → 라이트박스에서 인-게임 툴팁 원본 확대 (휠 줌 + 드래그 패닝 지원)
3. **트리 메인 화면 보기** — [활동 트리 개요](/activity-tree/) 의 7 트리 갤러리에서 전체 노드 그래프 확인
4. **함정 회피** — [지하도시 트리](/activity-tree/undercity/) 의 ⚠ 시련/공물 상자 경고 필독

## 갱신 계획

- 사용자가 정확한 트리 매핑 제공 시 그룹 갱신
- 노드별 한국명 + 효과 요약 텍스트 추가 (트리별 별도 페이지 또는 본 갤러리 인라인)
- 빌드 가이드 추천 노드 표시 (Maxroll/Mobalytics 메타 빌드 기준)
