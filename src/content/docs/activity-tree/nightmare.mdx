## 한 줄 요약

> 악몽 던전 트리는 **글리프 XP 증가 경로**가 빌드 초중반 효율의 핵심입니다. 후반 노드는 시질 변형을 강화해 보상을 늘리지만, 처치 속도가 느려질 수 있습니다.

## 잠금해제

악몽 던전 1회 클리어 시 등록. 후반 노드는 글리프 마스터 단계 이상에서 잠금해제됩니다.

## 권장 경로

| 단계 | 노드 | 효과 |
|------|------|------|
| 1 | 글리프 XP +20% | 가장 우선 |
| 2 | 시질 보상 +1 | 시질 자체의 가루 보상 증가 |
| 3 | 던전 내 엘리트 +2 | 엘리트 처치 효율 보정 |
| 4 | 보스방 보상 강화 | 보스 처치 시 매혹석/가루 추가 |
| 5 (후반) | 도전 변형 추가 | 추가 도전 시 보상 배수 |

## 사용 팁

- **초중반은 글리프 XP만 우선** — 다른 노드는 빌드 마무리 단계의 자원 잉여 시점에 분배합니다.
- **시질 보상 노드** — 시질 자체에서 떨어지는 가루가 늘어나므로, 악몽 던전 도는 횟수가 많은 캐릭터에게 누적 효율이 높습니다.

## FAQ

**Q. 글리프 마스터 잠금해제 조건은?**
A. 특정 글리프 레벨에 도달하면 자동 잠금해제됩니다. 시즌 초반에는 글리프 레벨 자체가 낮아 후반 노드 접근이 제한됩니다.
