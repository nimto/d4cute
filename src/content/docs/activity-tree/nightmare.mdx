## 잠금해제

악몽 던전 1회 클리어 시 등록. 후반 노드는 글리프 마스터 단계 이상에서 잠금해제됩니다.

## 경로별 상세

### 우측 경로 (Right Path) — <span class="kw-rare">메타 1순위</span>

- <span class="kw-rare">**Treasure Goblin**</span> — 보너스 이벤트 + 도깨비 등장 빈도 증가
- 도깨비 처치 시 추가 가루 + 잊혀진 영혼

### 좌측 경로 (Left Path) — 사당 정예 누적

- <span class="kw-rare">**사당(Shrine) 노드**</span> — 사당 1회 활성화 시 <span class="kw-gold">정예 7마리</span> 동시 등장
- 정예 누적 처치 카운트 빨리 채우는 데 효율적

### 중앙 경로 (Middle Path) — 글리프 XP 안정

- 글리프 XP +20% (선타격)
- 시질 보상 +1 (시질 자체의 가루 보상)
- 보스방 보상 강화

## FAQ

**Q. 글리프 마스터 잠금해제 조건은?**
A. 특정 글리프 레벨에 도달하면 자동 잠금해제됩니다. 시즌 초반 글리프 레벨이 낮아 후반 노드 접근이 제한됩니다.

**Q. 사당 정예 7마리는 매번 발생하나요?**
A. <span class="kw-rare">좌측 사당 노드 활성 시 사당 1회당 7마리 보장</span>. 사당 자체는 던전 내 무작위 등장.

**Q. Treasure Goblin 노드와 헬타이드 도깨비는 다른가요?**
A. 동일 시스템 — 둘 다 도깨비 등장 빈도 + 추가 가루/영혼. 두 활동 모두 우측 경로 분배 시 시너지.
